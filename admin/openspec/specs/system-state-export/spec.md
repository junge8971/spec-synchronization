# system-state-export Specification

## Purpose

Позволить выгружать актуальный серверный отбор рубильников и сохранённую карточку в CSV без имитации готового файла.

## Requirements

### Requirement: Export uses the complete server selection

Реестр SHALL предоставлять CSV-экспорт с выбором полей, поддержанных опубликованным API и metadata. Экспорт SHALL передавать полный применённый отбор и активный вид, не только загруженную страницу. Пределы и ошибки экспорта SHALL обрабатываться без незаметного усечения и без фиктивного успеха.

#### Scenario: Export a filtered paginated registry

- **WHEN** пользователь выбирает поля и экспортирует отбор, находясь на второй странице
- **THEN** сервер получает тот же полный отбор и выбранные поля, а результат не ограничивается строками второй страницы

#### Scenario: Export failure or limit

- **WHEN** backend возвращает ошибку или сообщает о превышении лимита
- **THEN** параметры остаются доступными, отображается ошибка и сообщение о готовом файле не появляется

### Requirement: Detail export reflects saved data

Карточка SHALL предоставлять действительный CSV-экспорт сохранённой записи через опубликованный detail endpoint с выбором поддержанных полей. Несохранённые изменения MUST NOT выдаваться за содержимое экспортируемого файла; при наличии черновика это различие SHALL объясняться. Новая неподтверждённая запись MUST NOT экспортироваться как сохранённая.

#### Scenario: Export with dirty fields

- **WHEN** пользователь изменил описание, не сохранил его и запускает экспорт карточки
- **THEN** UI объясняет, что выгружаются серверные сохранённые данные, и не отправляет черновик как файл

### Requirement: Export feedback is truthful and accessible

Успешный результат SHALL показываться только после проверки и передачи файла браузеру в доступном модальном результате согласно `operation-feedback`; UI MUST NOT утверждать, что файл гарантированно сохранён на диск. Возврат к параметрам SHALL сохранять выбранные поля без повторного экспорта. Неуспешная проверка файла или отказ передачи MUST NOT открывать успешный результат.

#### Scenario: Return to export parameters

- **WHEN** пользователь возвращается к параметрам после успешной передачи файла браузеру
- **THEN** прежние поля сохранены, повторный запрос отсутствует и новый экспорт требует явного действия
