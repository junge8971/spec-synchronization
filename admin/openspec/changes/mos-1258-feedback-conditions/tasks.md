## 1. MOS-1258 — Реализовать расширенные условия отбора опросников

- [ ] 1.1 Добавить редактор по metadata: name/code/description/type_code/status/audience_type/owner, разрешённые операторы, and/or и до 50 условий. Проверка: строки 1/1000/1001 символ, пробелы без trim, value/no-value/in/not_in, 1–100 уникальных кодов длиной 1–1000; очистка последнего кода удаляет условие; неизвестный оператор и неактивные lookup-коды; неподдержанные tags и вложенные группы не отправляются.
- [ ] 1.2 Связать draft/applied conditions, badge/bar/reset и полный URL с моделью MOS-1250. Проверка: status AND (A OR B), история/копирование, offset reset, одинаковый отбор для search/counts/export; независимый audience-фильтр не появляется и логика не меняется скрыто.
