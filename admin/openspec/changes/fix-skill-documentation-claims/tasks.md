## 1. Правдивая инструкция регистрации

- [ ] 1.1 Исправить шаги статьи `skill-register` под действующий четырёхшаговый мастер: создание/сохранение навыка вместо отсутствующих команд серверного черновика и отправки на проверку, локальное восстановление при доступном хранилище отдельно от серверной записи. Проверка: адресный unit-тест текста статьи подтверждает эти различия и отсутствие старого совета «Сохраните черновик или отправьте на проверку»; ID и порядок каталога сохранены.
- [ ] 1.2 Исправить пояснение пересечений: проверка не подключена, проверка заполненности и сохранение фраз не означают обучение/ревью. Сохранить объяснение назначения проверки через термин «неоднозначности». Проверка: позитивные/негативные assertions на содержимое и поиск по `НЕОДНОЗНАЧНОСТИ` находят `skill-register`, не обещая немедленный preflight и не меняя реализацию MOS-1018.
- [ ] 1.3 Добавить краткое пояснение частичной регистрации и неизвестного исхода по действующей spec: после подтверждённого создания продолжать незавершённый этап без нового создания, при неизвестном исходе не обещать безопасный повтор или гарантированный поиск ID. Проверка: unit-тест различает эти два случая и не допускает универсальной инструкции повторить регистрацию; бизнес-алгоритм не изменён.
