## Why

MOS-1027: требуется управляемое глобальное отключение и включение навыка. Для первой поставки достаточно видеть серверное состояние и подтверждать переключение по skill_id, без длительностей и подробного списка поверхностей.

## What Changes

- Согласованный минимальный MVP: серверное состояние «включён/отключён» и команды включения/отключения именно навыка по skill_id.
- Отдельное подтверждение каждого действия с названием навыка и пояснением глобальной области действия.
- Защита от повторной отправки, отображение только подтверждённого состояния, ошибки и перечитывание при неизвестном исходе без автоматических повторов.
- Длительности работы/отключения и подробный список затронутых поверхностей отложены и не блокируют MVP.
- Основание отключения и сообщение жителю не являются самостоятельным требованием минимальной формы; если будущий API потребует их, обязательность и валидацию нужно отразить при согласовании контракта, а не передавать фиктивные значения.
- Не использовать команды модулей, изменения конфигураций поверхностей или lifecycle-статусы как замену операции навыка.

## Capabilities

### New Capabilities

- `skill-global-toggle`: чтение серверного состояния и подтверждённое глобальное включение/отключение навыка.

### Modified Capabilities

Нет. Новый runtime-state не выводится из существующего SkillStatus и не синтезируется на клиенте.

## Impact

- После API-согласования: `app/widgets/skill-details/`, feature подтверждения, `app/entities/skill/`.
- **BLOCKED API сохраняется:** `docs/api/contracts/openapi.json` не предоставляет состояние включения и команды переключения по skill_id. Нужен минимальный контракт чтения/команд, их глобального эффекта и результатов; новые пути и поля до его появления не придумываются.
- API модулей/поверхностей не является API навыков. Наличие POST status не означает возможность отключить навык переводом в draft или добавить отсутствующий disabled.
- Не зависит от UI ревью/мониторинга. Приёмка ограничена минимальным переключением; расширенные сведения о последствиях и длительностях остаются вне поставки.
