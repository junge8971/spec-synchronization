## ADDED Requirements

### Requirement: Contract-compliant attachment actions succeed without weakening isolation

Для готового вложения UI SHALL выполнять явно выбранное скачивание либо разрешённый серверным `viewable` просмотр, если binary-ответ соответствует принятому контракту и гарантии безопасной передачи и изоляции подтверждены. Корректные значения заголовков SHALL оцениваться по их смыслу, включая допустимые регистр и дополнительные совместимые директивы; они MUST NOT отклоняться только из-за несущественного форматирования. Серверный контракт задаёт `Content-Type`, `Content-Disposition` с режимом и UTF-8 именем, `Content-Security-Policy: sandbox`, `X-Content-Type-Options: nosniff` и `Cache-Control: no-store`. При междоменном запросе необходимые для проверки заголовки SHALL быть доступны браузерному клиенту; их недоступность MUST NOT выдаваться за подтверждённую безопасность.

При отсутствии подтверждённой изоляции, несовпадении MIME, режима или размера, неполном ответе либо серверной ошибке UI SHALL показывать ошибку действия и MUST NOT открывать содержимое или сохранять ошибку как файл. Снимок карточки SHALL оставаться доступным. Ответ исходного запроса не заменяет безопасную изоляцию содержимого созданного browser blob. Ошибка просмотра MUST NOT запускать скачивание.

#### Scenario: Contract-compliant view and download

- **WHEN** сотрудник выбирает просмотр готового `viewable=true` изображения или PDF либо скачивание готового вложения и сервер возвращает соответствующий binary-ответ со всеми обязательными доступными заголовками и полным содержимым
- **THEN** выбранное действие завершается безопасным просмотром или скачиванием с серверным UTF-8 именем без сообщения о неподтверждённой безопасной передаче

#### Scenario: Equivalent secure header formatting

- **WHEN** корректный ответ содержит `no-store` вместе с совместимыми дополнительными cache-директивами, допустимый регистр и дополнительные CSP-директивы без отмены sandbox
- **THEN** UI не блокирует выбранное действие только из-за этих различий в форматировании

#### Scenario: SVG is download only

- **WHEN** сервер представляет готовое SVG-вложение с `viewable=false` и возвращает корректный ответ на скачивание
- **THEN** скачивание доступно, а действие просмотра не предлагается и автоматически не запускается

#### Scenario: Required security evidence is unavailable

- **WHEN** обязательный защитный заголовок отсутствует или недоступен браузерному клиенту либо выбранный просмотр нельзя безопасно изолировать
- **THEN** содержимое не открывается и не скачивается как успешный результат, показана доступная ошибка действия, а карточка остаётся доступной

#### Scenario: Invalid binary response

- **WHEN** ответ имеет неверный режим, MIME или размер либо содержит JSON-ошибку вместо файла
- **THEN** UI показывает ошибку без сохранения ошибочного содержимого и без автоматической подмены просмотра скачиванием
