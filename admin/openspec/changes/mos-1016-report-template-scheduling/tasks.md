## За границей текущего apply

Create/read API, полный набор сохраняемых настроек, относительный период, timezone, результат фонового запуска, видимость и ошибки/конфликты имени требуют согласования и обновления артефактов. Не переносить эти работы в текущий apply по предположению; UI-намерение расписания не является настроенным заданием сервера. Проверяемая полная приёмка находится в `design.md`, B16.1–B16.5: устойчивое create/read, полный round trip, период каждого запуска/timezone, видимость/результат и ошибки. После согласования API критерии переводятся в обновлённые specs/tasks, а не выполняются неявно в текущем apply.
