## Purpose

Обеспечить навигацию между конструктором и шаблонами отчётов, не выдавая отсутствие API каталога за успешно загруженный пустой список или готовые шаблоны.

## ADDED Requirements

### Requirement: URL-driven report tabs

Раздел `/reports` SHALL содержать вкладки «Шаблоны» (`templates`, по умолчанию) и «Конструктор» (`builder`). Отсутствующее, пустое или неизвестное значение `tab` SHALL показывать шаблоны. Переключение SHALL добавлять запись истории, сохранять прочие query-параметры, включая повторяющиеся, и удалять `tab` для вкладки по умолчанию. Повторный выбор активной вкладки MUST NOT создавать новую запись. Прямой вход, назад/вперёд и клавиатурная навигация SHALL восстанавливать правильную вкладку и крошки с учётом `/tsam-panel/`.

#### Scenario: Direct constructor link

- **WHEN** открыт `/tsam-panel/reports?tab=builder`
- **THEN** выбран конструктор, крошки показывают «Отчёты / Конструктор», а навигация отмечает раздел отчётов

#### Scenario: Default tab and history

- **WHEN** пользователь из `/reports?filter=a&filter=b&tab=builder` переключается на «Шаблоны», затем назад
- **THEN** сначала `tab` удаляется при сохранении двух `filter`, затем восстанавливаются конструктор и его крошки; на шаблонах крошки заканчиваются «Отчёты»

#### Scenario: Unknown tab

- **WHEN** пользователь открывает `/reports?tab=unknown`
- **THEN** показываются шаблоны без пустой страницы и без запроса несуществующего ресурса

### Requirement: Unavailable template catalog is not empty data

Вкладка шаблонов SHALL показывать «Не поддерживается текущим API» и пояснять недоступность списка, открытия сохранённых параметров и выгрузки шаблонов. Она SHALL предлагать переход в конструктор. UI MUST NOT показывать демонстрационные карточки, количество 0, «Шаблонов пока нет», вымышленные расписания/авторов/даты, бесконечную загрузку или retry несуществующего API.

#### Scenario: Open template catalog

- **WHEN** пользователь открывает вкладку шаблонов при текущем отсутствии контракта
- **THEN** показано unavailable-состояние без числового счётчика и без list/detail/export-запросов; доступен переход к локальному конструктору

#### Scenario: Go to constructor

- **WHEN** пользователь активирует переход «Открыть конструктор» с клавиатуры
- **THEN** выбирается `tab=builder` без имитации загрузки или запуска шаблона

### Requirement: Draft survives report tab navigation

Переключение между вкладками в пределах смонтированной страницы SHALL сохранять период, поверхность, порядок колонок и условия черновика; при наличии блока имени/расписания его ввод также SHALL сохраняться. Перезагрузка SHALL по-прежнему начинать новый несохранённый черновик. Навигация MUST NOT выдавать сохранение состояния в памяти за сохранение шаблона.

#### Scenario: Return to edited draft

- **WHEN** пользователь меняет колонки и условия, открывает шаблоны и возвращается в конструктор
- **THEN** черновик остаётся неизменным, включая порядок выбранных колонок, без обращения к API шаблона и без сообщения об успешном сохранении
