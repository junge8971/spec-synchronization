## 1. MOS-1255 — Реализовать интерактивный предпросмотр анкеты

- [ ] 1.1 Отрисовать семь типов из текущего draft с отдельным состоянием пробных ответов и маркировкой предпросмотра. Проверка: изменение title/options/required/order сразу видно, пустая анкета и неизвестный тип имеют честные состояния.
- [ ] 1.2 Реализовать пробные отправку/пропуск и очистку несовместимых ответов; никакого backend response API. Проверка: required учитывает 0/false, удалённый вариант/вопрос очищается, draft не меняется, сетевой запрос не отправляется, клавиатура и узкая компоновка доступны.
