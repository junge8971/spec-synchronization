# Spec Delta

## ADDED Requirements

### Requirement: Menu-only section visibility

В mock и real режимах оболочка SHALL показывать разрешённый существующими правилами пункт «Справочники» в группе «Эксплуатация» desktop и mobile sidebar. Выбор SHALL открывать существующий `/dictionaries` под текущим basename; реестр и вложенная карточка SHALL выделять этот пункт. Выбор на мобильном экране SHALL закрывать sidebar. Отсутствие доступа SHALL сохранять прежнее скрытие пункта и отказ при прямом входе без бизнес-запросов; возврат пункта MUST NOT расширять доступ.

Оболочка SHALL сохранять скрытыми следующие пять пунктов sidebar:

| Пункт приложения  | Корневой маршрут      |
| ----------------- | --------------------- |
| Документация      | `/docs`               |
| API               | `/api-registry`       |
| A/B эксперименты  | `/ab-testing`         |
| Шаблоны ответов   | `/response-templates` |
| Состояние системы | `/ops`                |

Эта политика SHALL определять видимость sidebar, включая нижнее меню документации; требования о существовании разделов и навигации по статьям MUST NOT возвращать пять скрытых пунктов. Скрытые пункты MUST NOT отображаться как ссылки, кнопки, disabled-заглушки или подсказки вместо пунктов и MUST NOT входить в клавиатурный обход. Пустые после фильтрации группы и нижний блок SHALL отсутствовать. Остальные разрешённые пункты SHALL сохранять порядок, названия, переходы и подсветку. Вкладка «Домены» в «Навыках» и справочники фильтров других экранов MUST NOT менять видимость из-за данного изменения.

Прямые URL всех разделов, создание, карточки, вкладки, совместимые адреса и существующие переходы вне sidebar SHALL сохранять прежнее поведение, включая basename, query, историю, заголовки, крошки, бизнес-валидацию и обработку ошибок. Ссылки на документацию вне sidebar и вводная справка SHALL сохраняться. Скрытие меню MUST NOT удалять функциональность, блокировать маршрут или менять существующие проверки доступа.

Состав видимых пунктов SHALL быть одинаковым для соответствующего доступа в mock и real режимах и на разных контурах развёртывания; отдельная проверка Т-контура или новое пользовательское включение раздела MUST NOT требоваться.

#### Scenario: Only dictionaries return

- **WHEN** пользователь с доступом ко всем существующим разделам открывает desktop sidebar в mock либо real режиме
- **THEN** пункт «Справочники» присутствует в «Эксплуатации», а пять перечисленных пунктов, документационный dropdown и пустой footer отсутствуют; остальные пункты сохраняют прежний порядок

#### Scenario: Dictionary registry and detail navigation

- **WHEN** пользователь выбирает «Справочники» либо открывает `/tsam-panel/dictionaries/<id>` напрямую
- **THEN** открывается существующий реестр либо самостоятельно загружаемая карточка, пункт «Справочники» выделен, заголовок, крошки и вкладки сохранены

#### Scenario: Mobile and keyboard navigation

- **WHEN** пользователь открывает mobile sidebar, фокусирует «Справочники» клавиатурой и выбирает этот пункт
- **THEN** выполняется переход в существующий раздел и sidebar закрывается; пять скрытых пунктов недоступны фокусу

#### Scenario: Access denied remains unchanged

- **WHEN** существующие правила не разрешают пользователю раздел справочников
- **THEN** пункт отсутствует, прямой URL показывает прежний отказ без бизнес-запросов и никаких новых прав не появляется

#### Scenario: Direct URLs of the other five sections

- **WHEN** пользователь с прежним доступом открывает прямую ссылку на один из пяти скрытых разделов или его карточку
- **THEN** сохраняются существующий экран, query, basename, заголовок, крошки и правила доступа, а скрытый пункт не появляется

#### Scenario: Deployment contour does not select visibility

- **WHEN** одно и то же приложение с одинаковым подтверждённым доступом используется на Т или другом контуре развёртывания
- **THEN** справочники возвращены и пять остальных пунктов скрыты по одной политике без дополнительного условия по контуру

#### Scenario: Contextual links and unrelated lookups

- **WHEN** пользователь использует ссылку на документацию вне sidebar, вводную справку, вкладку «Домены» или справочники фильтров
- **THEN** их существующие поведение, тексты и доступность сохранены
