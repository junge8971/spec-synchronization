## Why

MOS-945: вместо unavailable-вкладки обучающих фраз нужен редактор групп с серверным сохранением и честным отображением применения новой версии. HTML-прототип задаёт сценарий, но текущий API фразы не описывает.

## What Changes

- Показать группы, названия, фразы и счётчики; добавить создание/удаление группы, построчное редактирование, отмену и сохранение.
- В шаге мастера поддержать ввод по строкам или через запятую, когда отдельная задача создания навыка предоставит мастер.
- Для опубликованного навыка различать сохранённую и применённую версии, показывать дообучение по серверным данным.
- Не включать глобальные конфликты (MOS-1018), процесс проверок (MOS-1019) и создание всего мастера.

## Capabilities

### New Capabilities

- `skill-training-phrases`: группы обучающих фраз и состояние применения версии.

### Modified Capabilities

Нет. До появления согласованного API сохраняется unavailable из `control-center-api-integration`.

## Impact

- `app/widgets/skill-details/ui/tabs/intents-tab.tsx`, `app/entities/skill/`, предметная feature редактора.
- **BLOCKED API:** в `docs/api/contracts/openapi.json` отсутствуют чтение/сохранение групп, версии фраз и состояние применения. Нельзя отправлять придуманные поля в UpdateSkillRequest.
- **BLOCKED мастер:** `/skills/new` сейчас заглушка. Интеграция шага требует отдельной задачи создания, которой нет среди 13 Jira-задач; не считать её выполненной по component-тесту редактора.
- Самостоятельный change MOS-945; наличие макета/заглушки не закрывает приёмку.
