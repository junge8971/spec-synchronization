# MOS-1569 — локальная интерактивная проверка

## Условия

С отдельного разрешения пользователя проверено приложение из worktree `mos-1569-introductory-help`: `http://127.0.0.1:5188/tsam-panel/`, локальный Express mock — порт `3012`, Playwright MCP. Использованы фиктивные профили `viewer` и `none`; реальные сессии, credentials и внешние контуры не использовались. Изолированный браузерный контекст расширение создать не позволило (`Target.createBrowserContext: Not allowed`), поэтому использована отдельная вкладка на отдельном локальном origin/порту.

## Результаты

- При отсутствии `control-center-help-seen:1` и подтверждённом mock principal открылась справка поверх `/skills` с шага 1. На всех трёх шагах сверены заголовки, описания, «Где найти», счётчик, прогресс из трёх сегментов и подписи кнопок; переходы происходили без перезагрузки. Кнопки возврата не было.
- При завершении шагом «Начать работу», прерывании на шаге 2, нажатии крестика, Escape и клике по затемнённому фону диалог закрывался, для каждого способа была проверена запись `"1"` после предварительного удаления отметки. Фокус возвращался на «Открыть справку».
- Перезагрузка и переход `/skills` → `/surfaces` с отметкой `"1"` не вызвали автопоказ. Ручное открытие после прерывания и после завершения начиналось с шага 1 и сохраняло отметку.
- После удаления отметки переход `/surfaces` → `/skills` автоматически открыл шаг 1 без перезагрузки. Переход назад через историю с открытым шагом 2 сохранил шаг и фокус внутри диалога.
- Tab прошёл по «Прекратить» → «Далее» → «Закрыть» → «Прекратить»; Shift+Tab вернул фокус к «Закрыть». На viewport 375×240 диалог находился в пределах экрана, имел вертикальную прокрутку, фокус автоматически прокручивал элементы в видимую область, а клавиатурное завершение работало.
- Для имитации ошибки записи временно заблокирован `Storage.setItem` только для ключа справки. Диалог закрылся без падения и без записи, при переходе справка не появилась снова; ручное открытие оставалось доступно. После восстановления записи закрытие вновь сохранило `"1"`.
- Для имитации ошибки чтения при загрузке временно заблокирован `Storage.getItem` только для ключа справки. Справка автоматически открылась, закрылась и не повторилась при переходе `/skills` → `/docs`; ручное открытие также работало. Подмена удалена закрытием проверочной вкладки.
- При смене локального профиля с `viewer` на `none` отметка сохранилась, автопоказа не было; на экране «Нет доступа» кнопка справки открыла её с первого шага.

При первом старте Vite выполнял оптимизацию зависимостей и вернул несколько временных `504 Outdated Optimize Dep`; после повторного открытия страницы приложение работало. Последняя проверка консоли не показала ошибок. Проверочная вкладка закрыта, локальные dev/mock-серверы остановлены.

## Ограничения

Это интерактивная проверка локальных моков, а не подтверждение работы реальной MPMM-сессии или backend. Автоматические E2E и внешние стенды не запускались.
