## Why

[Jira MOS-1251](https://task.mos-team.ru/browse/MOS-1251): [FE][Обратная связь] Реализовать карточку опросника и правила показа.

Нужна отдельная реализуемая поставка этой FE-подзадачи по обновлённому API и принятой границе прототипа. План, приёмка и выполнение учитываются отдельно от остальных задач MOS-1246.

## What Changes

- Единый draft, три вкладки, поля карточки, поверхности, read-only ответственный, все display_rules, единое сохранение и точки подключения будущих редакторов. Вопросы — MOS-1254; метки — MOS-1257.
- Сохранить ограничения API, ввод при ошибках, доступность и действующую безопасность.
- Реализовать область задачи внутри `app/optional/feedback` по границе MOS-1249 и примеру базы знаний; новая UI-policy, mappings permissions и новые ограничения интерфейса по пользователю не входят.

- Показывать null опциональных полей пустым вводом, сохранять явные null в display_rules, проверять предел 100 поверхностей и подтверждать disabled также при обычном сохранении формы.
- Использовать готовый foundation MOS-1249 и существующие route entrypoints создания/деталей вместо заглушки редактора. Публичный index.ts остаётся API descriptors без runtime UI; application composition и границы раздела сохраняются.

### Deferred scope

Выбор ответственного из списка отложен до API пользователей. Уникальность названия не вводится. Выполнение триггеров и отправка опросников не реализуются.

## Capabilities

### New Capabilities

- `feedback-editor`: Единый draft, три вкладки, поля карточки, поверхности, read-only ответственный, все display_rules, единое сохранение и точки подключения будущих редакторов. Вопросы — MOS-1254; метки — MOS-1257.

### Modified Capabilities

Нет. Общие capabilities HTTP, действующих защитных механизмов и MPMM сохраняются; scope соседних FE-подзадач сюда не переносится.

## Impact

Владелец реализации и тестов — `app/optional/feedback`. Внешние подключения идут через публичный `index.ts` и отдельные framework route entrypoints; composition находится в application, нижние FSD-слои не зависят от optional.

Владелец редактора, формы, поверхности, display_rules и сохранение карточки.

Зависимости: [MOS-1249](../2026-10-16-mos-1249-feedback-api/proposal.md)

Базовая реализация MOS-1251 и локальные проверки завершены; стендовая приёмка подтверждена пользователем 23.10.2026. Интеграция конструктора вопросов остаётся в MOS-1254, меток и итоговой композиции после обеих задач — в MOS-1257.

Базовая реализация и стендовая приёмка MOS-1251 завершены; прежний task 1.5 вынесен в последующие MOS-1254/MOS-1257 по решению от 22.10.2026. Существующие вопросы, метки и их идентификаторы сохраняются в draft и при сохранении; их редакторы не входят в эту поставку.

Граница: UI по прототипу, операции по API, неподдержанное отложено. Исполнение правил и сбор реальных ответов пользователей не входят. Новые зависимости не требуются без отдельного обоснования. Это planning change: код приложения и Jira при разделении не меняются.
