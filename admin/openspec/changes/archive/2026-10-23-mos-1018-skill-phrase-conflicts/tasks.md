## 1. Согласованный single-phrase API

Политика согласована по live OpenAPI от 23.10.2026: preflight — подсказка; сохранение и `draft -> checking` не блокируются. Нормализация только серверная; граничные примеры остаются вопросом к backend. Скрытые данные отложены до появления DTO. Локальное сравнение и unavailable не являются завершением MOS-1018.

- [x] 1.1 Сверить и зафиксировать используемый single-phrase контракт по live OpenAPI: scope/self-exclusion, exact/semantic, score/order, обязательные skill/domain, независимость preflight от readiness. Проверка: контрактные материалы и design согласованы; сохранение и `draft -> checking` не блокируются, дальнейшее продвижение проверяется сервером по сохранённым данным; граничные примеры нормализации и скрытый DTO явно отложены. Сохранить границы MOS-945/MOS-1019, не реализуя отсутствующие lifecycle-команды.
- [x] 1.2 Подключить типы и клиент проверки через существующий transport; проверка: API-тест корректного запроса, malformed response и ошибки, yarn api:check.
