# Design

## Context

Модель массовых действий хранит общий выбор строк и проверяет возможность подтверждения. Панель использует причину блокировки, чтобы отключить кнопку и показать пояснение. Общий компонент уведомления отображает заголовок.

## Goals / Non-Goals

**Goals**

- Использовать одну проверку для доступности перевода, реакции на нажатие и подтверждения.
- Показать заголовок и описание через существующий провайдер уведомлений.

## Decisions

- Выделить отдельный результат проверки для непустого выбора без `approved`. Он блокирует команду и позволяет обработчику кнопки сбросить общий выбор и вызвать уведомление. Приоритет проверки доступности данных сохраняется.
- Обработать попытку открыть управляемый диалог в существующей точке входа. Для уведомления отменить открытие через API диалога. При допустимом выборе используется штатный диалог подтверждения.
- Добавить опциональное описание в общий компонент уведомлений через `Toast.Description` и показать его только при наличии текста. Проверить реестр с настоящей таблицей, моделью и провайдером уведомлений в компонентном тесте.
