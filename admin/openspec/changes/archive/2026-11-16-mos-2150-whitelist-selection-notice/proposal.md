# Proposal

## Why

В [MOS-2150](https://task.mos-team.ru/browse/MOS-2150) описано расхождение с прототипом. Если среди выбранных навыков нет согласованных, реестр блокирует кнопку перевода, показывает текст над таблицей и оставляет строки отмеченными.

## What Changes

- Назвать кнопку «В белые списки».
- По нажатию для непустого выбора без согласованных навыков показать уведомление и снять отметки в таблице.
- Смешанный выбор с согласованными и несогласованными навыками по-прежнему блокирует перевод всей группы с пояснением.

### Modified Capabilities

- `skill-bulk-rollout` описывает реакцию на выбор без согласованных навыков.

## Impact

Панель массовых действий реестра, проверка состава выбора, описание в штатном уведомлении и компонентные тесты.
