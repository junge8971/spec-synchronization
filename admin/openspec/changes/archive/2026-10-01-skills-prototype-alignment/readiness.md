# Матрица готовности skills-prototype-alignment

Текущая поставка — поддерживаемый UI и опубликованные бизнес-API, **не полная реализация прототипа**. Дельты G1/G3/G5/G6 и уточнённое сохранение G4 реализованы; прогресс **39/50**. Создание навыка включено без гарантированного replay по подтверждённому решению пользователя: при неизвестном исходе повтор POST запрещён. Новые состояния сохранения проверены component-тестами, но не в браузере. Повторная [визуальная проверка](visual-review.md) новых дельт выполнена по разрешению пользователя: после исправления горизонтального переполнения карточки на 390px финальные 211/211 проверок PASS, задача 20.3 закрыта. Geist сохранён по решению пользователя.

## Gates

- **G1:** расширение списка отложено. Неподдерживаемые колонки, статусный фильтр и предупреждения удалены без заглушек. Опубликованный каталог не заблокирован.
- **G2:** дополнительные ограничения/нормализация/уникальность отложены. Опубликованные CRUD, 422, версии и идемпотентность сохранены; коды из test doubles не объявляются backend-гарантией.
- **G3:** согласован и реализован GET `/teams/v1/teams/{team_id}/members` с limit/offset. Источник contact_user_id — ID участника. Выбор явный, без автоподстановки и role-фильтров. Кэш привязан к команде; неполная или ошибочная загрузка не доказывает исчезновение участника. Подтверждённое отсутствие в полном актуальном списке сбрасывает контакт.
- **G4:** уточнение пользователя реализовано. Backend replay больше не является условием включения. POST отправляется один раз, параллельные нажатия и автоматические retry блокируются. При неизвестном исходе сохранён ввод, показаны предупреждение о возможном создании/дубле и переход к реестру; повтор POST отсутствует. После подтверждённого ID ошибки GET/PUT восстанавливаются без повторного создания; версия и ключ PUT сохраняются. Документированный отказ 422 позволяет исправить анкету и начать новую попытку, но не считается неизвестным исходом. Гарантия отсутствия дублей backend не заявляется.
- **G5:** lifecycle отложен; блок, шкала, заглушки и команды скрыты. Локальный draft не удалён и не выдаётся за серверный черновик.
- **G6:** вкладка ревью, проверки конфликтов, готовность и мониторинг видимы с пояснениями рядом, без фиктивных данных/успехов и запросов к придуманным endpoints. Профильные интеграции MOS-1018/1019/1020/1025/1026 остаются открытыми; исключения G1/G5 сохранены.

## Проверенные сценарии

- Каталог: длинные данные, null ID, integer version, server total, пагинация, удалённые элементы G1, неподдержанный sort, URL/debounce/back/forward, 101-й вариант справочника, empty/error/retry.
- Домены: прежние client/component и сквозные route-тесты сохранены; создание домена обновляет варианты мастера.
- Контакты: 101-й участник и его ID; пустой/невалидный/неполный ответ; смена команды и поздний ответ; ошибка/повтор; сохранение прочих полей; отсутствие на первой странице не сбрасывает выбранного участника; подтверждённое удаление сбрасывает. Сводка показывает новый контакт после изменения анкеты.
- Мастер: четыре шага, ошибки/границы фраз, dirty-уход, отдельный auth_required, скрытые команды G5 и пояснения G6. Проверены POST/GET/PUT, двойное нажатие, потеря ответа/невалидный DTO/204/503, отказ 422 с исправлением, частичный результат, повтор GET/PUT, конфликт без новой версии, сбой фонового refetch и снятие dirty-блокировки только после полного успеха.
- Карточка: поддерживаемые анкета/фразы/подключение, отсутствие lifecycle-заглушки и команд, видимые пояснения G6; открытие вкладок не вызывает вымышленных запросов.
- Сквозной component-тест с настоящими route-модулями и HTTP doubles проверяет домен → мастер → создание → ошибка фраз → повтор → карточка с фразами → домены со skills_count=1 → реестр с total=1 и domain_id под basename. Один POST навыка, неизменённые тело/ключ PUT, отсутствие auth-запросов. Возврат из карточки в отфильтрованный реестр по-прежнему покрыт отдельным тестом. Реальный backend не проверялся.
