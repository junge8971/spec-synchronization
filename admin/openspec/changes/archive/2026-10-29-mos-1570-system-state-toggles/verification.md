# Проверки реализации — 28.10.2026

## Перенос в основной проект, ветка `MOS-1570`

- Изменения перенесены без коммита в основной checkout от актуального `dev` (`1218656`); исходный worktree сохранён. Отслеживаемый diff совпадает с исходным, все 123 новых файла проверены побайтно. OpenSpec и локальный `AGENTS.md` перенесены отдельно, поскольку игнорируются Git.
- На новом основании прошли `yarn typecheck`, `yarn lint`, `yarn api:check`, `yarn build`, строгая OpenSpec-валидация и `git diff --check`. `yarn test`: 252 файла Vitest, 2573 теста и 399 node/mock/архитектурных тестов. Производственный граф содержит UI system-state без модулей `mocks/`; Vite предупреждает о чанках более 500 kB.
- Адресная проверка Prettier изменённых файлов прошла. Общий `yarn format:check` не прошёл из-за 667 существующих игнорируемых файлов: 529 материалов backlog-аудита и 138 снимков `.playwright-mcp/`. Форматирование этих чужих файлов не изменялось.

## Пройдено

- `openspec validate mos-1570-system-state-toggles --strict`.
- `yarn typecheck`, `yarn lint` без предупреждений, `yarn api:check` и `git diff --check`.
- Повторный последовательный `yarn test`: 251 файл Vitest, 2538 тестов; затем 399 node/mock/архитектурных тестов, без ошибок.
- `yarn build`: успешная production-сборка; предупреждение Vite о чанках более 500 kB. Проверка графа client-сборки нашла registry UI и detail route system-state, но ни одного модуля `mocks/`. Тонкий registry route оптимизирован сборщиком, поэтому проверяется итоговый UI-модуль, а не его отсутствие как отдельного модуля.
- Адресный `yarn prettier --check --ignore-unknown` по всем изменённым и новым исходникам/мокам прошёл.
- В отдельной временной копии после отсоединения composition, route, mock и lint registrations и удаления optional-модуля прошли `yarn typecheck`, `yarn build` и 16 профильных route/session component-тестов. Typegen сохранил `/ops`, `/ops/stubs`, `/ops/maintenance` и маршруты остальных модулей.
- Локальная интерактивная проверка с пользовательским разрешением описана в `browser-check.md`.

## Не прошли при первом запуске / ограничения

- Первый общий `yarn test`, запущенный параллельно с lint и format, упал по таймауту существующего теста feedback `prevents a 101st question and enables adding after deletion`; при самостоятельном запуске и повторном последовательном полном прогоне он прошёл. Таймаут и утверждения не менялись.
- `yarn format:check` не прошёл: все 529 замечаний относятся к существующим игнорируемым материалам `openspec/changes/reconcile-control-center-backlog/`, а не к изменённым файлам. Широкие исключения и переформатирование чужого аудита не добавлялись.
- Первый диагностический assert графа ожидал отдельный `routes/registry.tsx`, который сборщик схлопнул; исправленный assert проверяет присутствие реального registry UI и detail route и отсутствие всех `mocks/`.

## Не проверено и не заявлено готовым

- Автоматические E2E/browser-тесты и внешние тестовые контуры не запускались; разрешение распространялось только на локальную интерактивную проверку.
- Отсутствуют подтверждения backend о global state source для не-администраторов, полном mapping кодов на маршруты, немедленном серверном применении/enforcement, server authorization, ownership saved filters и аудите. Эти пункты и общая приёмка выпуска остаются открытыми. Одноэлементный `kind` проверяется чтением после сохранения, но реальный backend не проверен.
- Изменения находятся в worktree и не закоммичены; значительная часть новых файлов не отслеживается Git. Локальные OpenSpec-артефакты и `AGENTS.md` игнорируются Git и требуют учёта при передаче.
