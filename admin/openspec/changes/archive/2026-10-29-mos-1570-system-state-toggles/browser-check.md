# Интерактивная локальная проверка — 28.10.2026

Выполнена по отдельному разрешению пользователя через Playwright MCP в worktree с локальными Express-моками. Внешние контуры и их данные не использовались; автоматические E2E/browser-наборы не создавались и не запускались.

## Проверено

- С профилем `Демо: просмотр` (`TSAM.Module:view`) `/ops?tab=modules` показывает прежнюю заглушку; прямой переход к карточке показывает «Нет доступа». Запросов к `/managed-resources/system-state` не было. С `Демо: полный доступ` (`*`) доступен новый реестр.
- Старые вкладки «Заглушки» и «Технические работы» и адреса `/ops/stubs?source=legacy`, `/ops/maintenance?source=legacy` сохранены. Перенаправления и переключение вкладок сохраняют посторонние query-параметры.
- Реестр показывает серверную сводку и строки, переключает виды, применяет серверные поиск и сортировку, показывает разделы всей вкладки и горизонтальную прокрутку на узком экране. Клавиатурная смена внешней вкладки и сортировка сохраняют фокус. Исправление повторного session bootstrap в локальном демо отдельно покрыто тестами; исходный `dev` терял фокус до исправления.
- Конструктор условий отклоняет пустое значение и применяет `code contains mod_kb` с серверным результатом. Локальный сохранённый отбор с одинаковым именем обновлён с прежним ID, затем удалён. Это не подтверждает ownership или upsert реального backend.
- Критичное отключение сначала отменено без изменения, затем подтверждено; состояние, дата и автор обновились. Включение локальной записи восстановлено.
- Создание с занятым `mod_kb` показало серверный 409 и сохранило поля. Созданная локальная custom-запись открылась по возвращённому ID. Несохранённое описание пережило независимое переключение; выход потребовал подтверждения, отмена вернула фокус и сохранила черновик. Сохранение подтвердилось, удаление с подтверждением вернуло в реестр. Тестовые записи удалены из локального mock-состояния.
- Реестровый CSV передан браузеру, результат не утверждает сохранение на диск; возврат к параметрам сохранил снятый флажок и не инициировал повторный экспорт. Файл создан локальным mock API.

## Замечания и ограничения

- Проверка обнаружила лишний GET удалённой записи после DELETE; очистка cache перенесена на размонтирование карточки. Повторное локальное создание и удаление прошли без ошибок/предупреждений консоли и без повторного GET.
- После серии Vite HMR возникло предупреждение роутера о нескольких blockers; после полной перезагрузки и повторения сценария выхода предупреждение не воспроизвелось. Ожидаемый серверный 409 при проверке дубликата отражается браузером в консоли как failed resource.
- Невалидный ID, 403/404/500, повреждённый CSV, ошибка clipboard, неизвестные исходы и поздний ответ другого пользователя дополнительно проверены unit/component-тестами; реальные 403/404 и реальный контур в браузере не проверялись.
- Глобальное отключение разделов, backend authorization, audit и изоляция сохранённых отборов остаются внешними release gates. Моки и локальная проверка не подтверждают их работу.
