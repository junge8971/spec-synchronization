- Ручная browser-проверка выполнена после разрешения пользователя только на локальных моках; автоматические E2E/browser-тесты и операции на внешних контурах не запускались.
- Итоговый diff и независимый review проверены; `git diff --check` пройден. Артефакты `add-skill-csv-export` и `mos-909-restore-approved-lifecycle-actions` идентичны исходному checkout; ранее незавершённая приёмка не закрывалась.

## Ручная проверка локальных моков

- `approved → whitelist`: после подготовки двух локальных записей одна команда подтвердилась, другая получила 409 из-за изменённой после подтверждения версии; отчёт показал 1 из 2. `whitelist → prod`: два перехода подтвердились, отчёт сохранил предыдущий конфликт.
- CSV реестра: все 19 полей выбраны по умолчанию, поле ID снято клавиатурой, запрос содержал 18 полей и применённый статус `approved`; результат показан в том же диалоге. Возврат сохранил выбор без нового запроса. CSV карточки: все поля, тело `{}` без `fields`, результат и возврат к параметрам.
- Уведомления: показаны подтверждённые отправка черновика на проверку, отключение и включение навыка, сохранение нового правила справочника; создание пустой строки само по себе уведомления не вызвало.
- Ошибки: пустое основание/сообщение отключения вызвало валидацию; выбранный mock HTTP 500 для статуса не вызвал toast успеха, показал неизвестный исход и потребовал явного перечитывания. HTTP 500 для CSV оставил параметры и показал ошибку без результата выгрузки.
- Клавиатура: Space переключает выбор строк и поля CSV, Tab/Enter подтверждают массовое действие, Escape закрывает CSV и возвращает фокус на кнопку экспорта. Вкладка и локальный сервер остановлены; изменённый mock seed не сохраняется после остановки.
- Наблюдение вне scope: у пустой новой строки правил видны английские сообщения валидации Zod (`Too small`, `Invalid input`); отображающий их `dictionary-editor-cell.tsx` этим change не изменялся.

## Визуальное сравнение

- В [MOS-1775](https://task.mos-team.ru/browse/MOS-1775) указан пример других разделов, отдельного макета в задаче нет. В локальном UI диалог массового перевода использует тот же компонент и структуру, что существующее подтверждение выката в prod; новые уведомления используют общий компонент уведомлений.
- Диалог CSV навыков совпадает по базовому UI-kit, но отличается от локальных форм поверхностей и справочников: две колонки вместо одной, без крестика в заголовке и с отдельными кнопками «Закрыть»/«Скачать» вместо полноширинной «Скачать CSV». В форму навыков не добавлялась настройка порядка, поскольку его определяет сервер. Точное визуальное соответствие примерам не утверждается; требуется согласовать, нужно ли выравнивание.
- Просмотрен также диалог навыков при 360×800; это не проверка всех экранов и браузеров. Снимки локальных окон сохранены в `.playwright-mcp/mos-1772-visual-review/` worktree; каталог исключён из Git.
