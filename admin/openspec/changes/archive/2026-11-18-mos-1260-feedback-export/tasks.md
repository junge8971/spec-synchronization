### Результаты локальных проверок (18.11.2026)

- `yarn typecheck`, `yarn lint` (без предупреждений), `yarn format:check`, `yarn build` — PASS.
- `yarn test`: первоначальный полный запуск до финальных дополнений прошёл (2087 тестов); финальный запуск с обычным числом workers получил 4 таймаута по 5000 мс в dialog-registry-list-search и editor-labels-integration. Повтор полного набора `yarn test --maxWorkers=2` — PASS: 244 файла, 2089 тестов. Пороги и утверждения не изменялись.
- `node --test mocks/feedback/*.test.mjs` — PASS: 4 теста, включая два CSV, лимит и максимальный отбор.
- `git diff --check` — PASS; просмотрены изменённые и новые файлы, предметный код остался в feedback. Дополнительная проверка production JS не обнаружила маркеров реализации feedback-моков.
- `yarn api:check` не запускался: generated/API-контракты не менялись.
- 4.3 — PASS после отдельного разрешения пользователя: Playwright MCP, `http://127.0.0.1:5173/tsam-panel/feedback`, `CONTROL_API_MOCKS=true yarn dev`, локальный профиль full. Выполнены интерактивные проверки, автоматизированные E2E-файлы не создавались и не запускались. Структура модалки визуально сверена со прочитанным HTML-прототипом и UI kit проекта.
  - На локальном seed из 25 специально созданных опросников таблица показывает 20 строк, экспорт — 25 записей. У инициированного скачивания проверены Blob, BOM `[239,187,191]`, серверное имя и порядок заголовков после перемещения «Служебный код» первым. Файл не строится из страницы.
  - Возврат к параметрам и повторное открытие сохраняют порядок; снятие всех чекбоксов блокирует экспорт с пояснением. Enter перемещает колонку, Space меняет чекбокс, Tab остаётся внутри окна. Esc, кнопка и клик вне закрывают окно с возвратом фокуса к «Экспорт».
  - При 390×844 окно укладывается в ширину (отступ 16 px, ширина до 358 px), управляющие элементы доступны, горизонтального overflow страницы нет. Desktop проверен при 1280×900.
  - Реальный запрос локального mock API с пустым отбором возвращает header-only CSV и результат 0. Dirty-карточка при изменённом code отправляет только fields, CSV и результат содержат сохранённый code, draft не меняется; предупреждения есть в обоих окнах. На новой карточке кнопка недоступна.
  - Только для локального export URL через Playwright route воспроизведены 403, 500, 422 EXPORT_LIMIT_EXCEEDED и HTML вместо CSV: показаны ошибки, сохранён выбор, нет скачивания/окна успеха. Перехваты удалены после сценариев. Это проверка UI-обработки, не реального превышения лимита стенда.
  - Удержанный локальный ответ: pending блокирует отправку, Esc отменяет запрос; поздний ответ не создаёт Blob-скачивание и окно результата, фокус восстановлен.
  - Событие Playwright `download` не было получено адаптером (таймаут); вместо него проверены фактический click ссылки download, содержимое её Blob и окно результата. Запись файла на диск не утверждается. Первоначальные actionability-таймауты устранены выводом вкладки на передний план; дефект приложения по ним не заявляется.
- 4.4 не выполнен: стендовые запросы не согласованы и не выполнялись. UI-права по 5.1 не согласованы; новые mappings не добавлялись.

### Дополнение: drag-and-drop колонок (по запросу пользователя)

- В 2.2 добавлено нативное перетаскивание выбранных колонок; кнопки выше/ниже оставлены для клавиатуры и touch. Новых зависимостей нет. Обработчики находятся в `app/optional/feedback/handlers/export-field-reorder.ts`.
