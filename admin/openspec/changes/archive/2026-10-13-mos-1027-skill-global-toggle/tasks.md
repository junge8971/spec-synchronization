- Реализованы клиент, полоса состояния, обе формы, проверки версии/сессии, защита от повторов и восстановление чтением. Поздняя успешная команда инвалидирует только соответствующую карточку даже после ухода и возврата; перечитывание не синтезирует version.
- Пройдены `yarn typecheck`, `yarn lint` без предупреждений, `yarn format:check`, `yarn api:check`, `yarn test`: 117 файлов / 1135 unit/component-тестов и 86 Node/mock/SPA-тестов. HTTP-тесты выполнялись с разрешённым loopback вне sandbox. После последней правки тестового списка отдельно пройдены 18 component-тестов feature.
- Первичные ошибки типов тестовых fixtures, форматирования и complexity исправлены без ослабления правил. Финальные проверки зелёные; независимый review закрыт, scope-diff проверен, прежние пользовательские изменения сохранены.
- `yarn build` не запускался: конфигурация сборки не менялась. Browser/E2E-тесты не запускались. Реальные команды backend не выполнялись. После локальной проверки пользователь подтвердил корректность реализации по результатам консультации с backend; пункт 4.1 закрыт этим согласованием, а не mock-тестами. Swagger просмотрен в Chrome без выполнения POST; матрица переходов и concurrency-коды в нём отсутствуют. Интеграционный прогон не заявляется пройденным.
