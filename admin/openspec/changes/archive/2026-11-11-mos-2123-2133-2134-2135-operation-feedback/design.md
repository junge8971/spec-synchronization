# Design

## Context

`NotificationProvider` уже подключён в корне приложения. `useOperationNotification` публикует toast с низким приоритетом, заменяет предыдущее уведомление этой операции и отбрасывает запоздалый результат после смены контекста. Действующие точки завершения операций описаны ниже. Мотивация и охват приведены в [proposal.md](proposal.md), условия показа и тексты — в [дельте operation-feedback](specs/operation-feedback/spec.md).

## Goals / Non-Goals

**Goals.** Публиковать подтверждение из обработчика операции с подходящим временем жизни. Сохранить доступное закрытие, фокус и действующие пути восстановления после ошибок.

**Non-Goals.** Экспорт, изменения бизнес-операций и контрактов, пересмотр доступа к разделам.

Раздел «Обратная связь» уже подключён по модели базы знаний. Его публичный `index.ts` отдаёт только дескрипторы маршрутов и вкладок. Маршрутные адаптеры, UI опросников, запросы и клиенты принадлежат `app/optional/feedback`. Анкета навыка и рубильники используют общий механизм из `app/shared/ui/notifications`. Проверки регистрации раздела и границ импортов остаются частью проверки change.

## Decisions

1. **Использовать общий toast с временем показа для конкретного вызова.** Добавить в `notifySuccess` необязательный параметр таймера, который передаётся в существующий toast manager Base UI. Для анкеты передать 3000 мс. Остальные вызовы используют значение провайдера. Стандартное закрытие и пауза при взаимодействии остаются у общего компонента.
2. **Привязать подтверждение анкеты к успешному ответу мутации.** Развести в `SkillEditingForm` подтверждённое сохранение и закрытие при пустом наборе правок. Вызвать уведомление после завершения `useUpdateSkillMutation` и проверки действующего контекста, затем закрыть форму штатным способом. Общий `onSaved` сейчас вызывается и при пустой правке, поэтому его безусловное использование показало бы ложный успех.
3. **Объединить подтверждение сохранения отбора в точке успешной проверки.** Первичная операция `useSystemStateSavedFilters` выполняет запись и сверку чтением. `recheck` повторяет только чтение. Оба подтверждённых пути проходят через `verified`. Передать результат в уведомление владельца меню из этой общей точки, чтобы оба пути давали одинаковый результат ровно один раз. Убрать прежнюю встроенную копию сообщения о сохранении. Сообщения об удалении, прекращении проверки и ошибках сохранить.
4. **Поднимать результат переключения до владельца экрана.** В `useSystemStateToggle` использовать общий обработчик успешной мутации для обычного переключения и отключения с подтверждением. Передать подтверждённое `result.enabled` в уведомление, которое принадлежит экрану реестра или карточке и сохраняется после обновления данных. Вызов на уровне отдельной строки может потеряться, когда обновлённый рубильник перестаёт соответствовать отбору. Сверка после ошибки остаётся отдельным чтением и показывает результат сверки.
5. **Оставить копирование в `RegistryCopyLink`.** Заменить встроенный текст успеха на вызов общего уведомления после `clipboard.writeText`. Сохранить текущую ссылку и сообщение об ошибке с ручным копированием. Проверять актуальность владельца и отбора перед публикацией позднего результата.

## Risks / Trade-offs

- Обновление списка может размонтировать строку до завершения колбэка. Использовать колбэк жизненного цикла мутации и уведомление с временем жизни экрана. Проверить исчезновение строки после серверного ответа компонентным тестом.
- Запрос может завершиться после перехода на другой экран, открытия другого рубильника или смены пользователя. Переиспользовать текущие проверки ответа и владельца операции, а контекст toast привязать к экрану и объекту там, где это применимо. В реестре обновление результатов само по себе сохраняет контекст. Для копирования контекст включает текущий URL отбора.
- Единый таймер провайдера изменил бы время жизни других уведомлений. Проверить локальное переопределение и вызов без него в тестах общего механизма.

## Migration Plan

Поставка входит в обычное обновление фронтенда. Откат выполняется возвратом изменений фронтенда.
