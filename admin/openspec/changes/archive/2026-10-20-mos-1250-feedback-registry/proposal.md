## Why

[Jira MOS-1250](https://task.mos-team.ru/browse/MOS-1250): [FE][Обратная связь] Реализовать реестр опросников и базовый отбор.

Нужна отдельная реализуемая поставка этой FE-подзадачи по обновлённому API и принятой границе прототипа. План, приёмка и выполнение учитываются отдельно от остальных задач MOS-1246.

## What Changes

- Навигация, реестр, базовые status/type_code, query, сортировки, пагинация и общий applied search/URL. Конструктор conditions принадлежит MOS-1258.
- Сохранить ограничения API, ввод при ошибках, доступность и действующую безопасность.
- Реализовать область задачи внутри `app/optional/feedback` по границе MOS-1249 и примеру базы знаний; новая UI-policy, mappings permissions и новые ограничения интерфейса по пользователю не входят.

### Deferred scope

Поиск по названиям типов/тегам/сегментам/поверхностям, сортировка по аудитории и отдельный фильтр аудитории отложены. Редактор conditions — MOS-1258.

Приёмка ограничена описанным UI и его прямыми интеграциями. Закрытие всей группы MOS-1246 в эту задачу не входит.

## Capabilities

### New Capabilities

- `feedback-registry`: Навигация, реестр, базовые status/type_code, query, сортировки, пагинация и общий applied search/URL. Конструктор conditions принадлежит MOS-1258.

### Modified Capabilities

Нет. Общие capabilities HTTP, действующих защитных механизмов и MPMM сохраняются; scope соседних FE-подзадач сюда не переносится.

## Impact

Владелец реализации и тестов — `app/optional/feedback`. Внешние подключения идут через публичный `index.ts` и отдельные framework route entrypoints; composition находится в application, нижние FSD-слои не зависят от optional.

Application route composition, навигация, реестр и внутренняя модель отбора feedback.

Зависимости: [MOS-1249](../2026-10-16-mos-1249-feedback-api/proposal.md)

Граница: UI по прототипу, операции по API, неподдержанное отложено. Исполнение правил и сбор реальных ответов пользователей не входят. Новые зависимости не требуются без отдельного обоснования. Реализация выполняется по tasks этой подзадачи; состояние Jira автоматически не меняется.

## Решение о закрытии — 20.10.2026

После сообщения о недоступном стенде и сохранения плана последующего UI-прогона пользователь явно поручил: «закрой тогда задачу с проверкой». MOS-1250 закрыта с принятой непроведённой стендовой проверкой пункта 2.3. Это не подтверждение серверного поиска, счётчиков, пагинации, lookup или успешного интеграционного прогона. План проверки и внешние материалы сохранены для выполнения после восстановления доступности; продуктовые требования и scope соседних задач не меняются. Состояние Jira автоматически не изменяется.
