## Why

MOS-1037: вместо заглушки `/dialogs` нужен серверный реестр нового прототипа. Обновлённый проект контракта уже описывает 12 полей строки, сортировку и курсор; прежнее замечание о недостающих полях больше не отражает целевую модель.

## What Changes

- Реестр с колонками «Обращение и участники», «Начало», «Завершение», «Поверхность», «Оценка работы оператора», «Время».
- Поиск q, календарный период, множественные фильтры поверхностей/навыков, пять серверных сортировок, накопление страниц кнопкой «Показать ещё».
- Единый версионированный selection для MOS-1038, MOS-1040 и будущего MOS-1045; без локального поиска по загруженным строкам.
- Серверные total/data_updated_at, корректные loading/empty/error/retry и переход по chat_id.
- Закрепление бизнес-части согласованного контракта при реализации, но не автоматическое объявление PDF опубликованным API.

## Capabilities

### New Capabilities

- `dialog-registry`: реестр, базовый отбор, серверная сортировка и курсорная пагинация.

### Modified Capabilities

Нет. Существующие правила HTTP, ошибок и оболочки сохраняются; новая предметная спецификация не меняет offset-пагинацию других реестров.

## Impact

- `app/routes/dialogs.tsx` сейчас использует PlaceholderPage; планируются `pages/dialogs`, предметный публичный API `entities/dialog`, композиция реестра без импортов соседних features.
- Целевые методы PDF: `POST /api/control/api/dialogs/v1/dialogs/search`, `GET /api/control/api/dialogs/v1/dictionaries`.
- Источники: скриншот MOS-1037; `/home/user/Загрузки/Прототип. Центр управления.html`; PDF `/home/user/Загрузки/241085439_bf1810bba3974ef1b9dbac2d3a41d66b-051026-1642-740.pdf`, версия v1.0, разделы 2.4, 2.6, 3.1–3.2, 7–8. PDF — проработка Confluence с предположениями, не доказательство готовности ЕСК.
- **GATE принят:** пользователь подтвердил бизнес-контракт («принимаем контракт»); принятые решения по поиску ЕСК, chat_id, времени/периодам и справочникам зафиксированы в design. Search/dictionaries опубликованы в `docs/api/contracts/dialogs.md` и OpenAPI, DTO сгенерированы штатно. Проверка доступности развёрнутого ЕСК не заменяется этим согласованием; runtime fixtures запрещены.
- MOS-1037 владеет общими selection/search/dictionaries; MOS-1041 — detail/attachments. MOS-1038, MOS-1040 и MOS-1045 используют эту основу, но имеют самостоятельную приёмку. Отметки строк и экспорт относятся к MOS-1045.
