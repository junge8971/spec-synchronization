## Результаты проверок в worktree

- `VITEST_MAX_WORKERS=2 yarn test` — успешно после исправления: 258 Vitest-файлов, 2620 тестов и 407 Node-тестов; лог `/tmp/mos-1755-1573-final-test.log`.
- `yarn typecheck`, `yarn lint`, `yarn api:check`, `yarn build` — успешно после исправления; сборка сохранила предупреждение Vite о чанке более 500 kB. Сборка с `CONTROL_API_MOCKS=true` также выполнена; mock handler и demo fixture не найдены в build.
- `yarn format:check` — ошибка на 529 ранее существовавших файлах `openspec/changes/reconcile-control-center-backlog/audit/`; затронутые файлы отдельно прошли `prettier --check`. Лог `/tmp/mos-1755-1573-final-format.log`.
- Локальная интерактивная проверка через Playwright MCP с разрешения пользователя, профиль `Демо: полный доступ`: в справочнике `attachment_rules` отображены 11 пройденных, 2 неуспешных и 1 пропущенная проверки и счётчик 2; переход стрелками/Enter работает. Повторная проверка сохранила несохранённое описание и показала результаты сохранённых данных. На узком экране действие перепроверки доступно с клавиатуры и помещается в область просмотра без горизонтального переполнения.
- Экспорт реестра: отбор `город`/`sandbox`/`portal`, сортировка `-name` и выбор 11 из 12 полей переданы в POST без пагинации; ответ CSV содержит выбранную запись. Экспорт со второй страницы вернул все 20 записей без параметров страницы. `Escape` закрыл диалог и вернул фокус кнопке.
- Найденное при первом открытии вкладки предупреждение React `Cannot update a component (DictionaryDetailTabs) while rendering a different component (DictionaryChecks)` воспроизведено component-тестом и исправлено: подписка сравнивает только актуальный счётчик. После исправления повторное открытие вкладки в браузере без ошибок консоли.
- Экспорт dirty-карточки: показано предупреждение, выбрано 11 полей с клавиатуры, сохранённые данные возвращены CSV, изменения конфигурации остались в черновике без PUT; `Escape` закрыл результат и вернул фокус. При mock HTTP 403 показана ошибка без ложного успеха, выбор полей сохранён, `Escape` работает. Сценарии моков сброшены после проверки.
- Автоматические E2E/browser suites не запускались. Реальные CSV, CORS и backend-авторизация не проверялись.
