## Why

MOS-1021: реестр не позволяет выбрать несколько навыков и выполнить контролируемый выкат с результатом по каждому. Для первой поставки достаточно распространить существующий одиночный переход из белых списков в prod на выбранные строки, не ожидая отдельного batch API.

## What Changes

- Чекбоксы строк, «выбрать все показанные», панель выбранных навыков; выбор сбрасывается при смене страницы, фильтра или сортировки.
- Согласованный MVP: только `whitelist → prod`, одно подтверждение продуктивного контура и количества навыков.
- Последовательные одиночные POST status с expected_version и UUID Idempotency-Key; одновременно выполняется не более одного запроса смены статуса.
- Результат по каждому навыку, включая частичные ошибки и неизвестный исход; обновление реестра без автоматических повторов команд.
- Переход «согласован → белые списки» отложен: в контракте нет approved. Его отсутствие не блокирует этот MVP; review не подменяет согласование.

## Capabilities

### New Capabilities

- `skill-bulk-rollout`: выбор показанных навыков и массовый выкат из белых списков в prod с результатом по каждому.

### Modified Capabilities

Нет. Существующие серверный status-фильтр, отображение SkillStatus и одиночный lifecycle сохраняются.

## Impact

- `app/widgets/skills-registry/`, существующий клиент `app/entities/skill/`, предметная feature массового выката.
- Используется опубликованный POST `/api/control/api/skills/v1/skills/{skill_id}/status`; новый endpoint и изменения контракта не требуются. Пользователь согласовал последовательные команды и ограничение MVP переходом `whitelist → prod`, уже принятым для MOS-909. Это продуктовое допущение, а не гарантия допустимости перехода backend.
- Нет зависимости от готовности MOS-1020: этот change не реализует решение ревью, статус approved или выкат в белые списки. Surface publish не используется.
- Отдельная приёмка согласованного MVP MOS-1021; отложенный переход не объявляется реализованным. Batch API, фоновое выполнение, автоматические повторы и восстановление очереди после перезагрузки не входят в поставку.
