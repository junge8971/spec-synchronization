# Proposal

## Why

В карточке поверхности вкладки «Подключение» и «Обзор» пока показывают заглушки, хотя API уже возвращает сведения для них. MOS-913 должен дать команде доступ к сохранённым данным и точному серверному коду подключения без фиктивных токенов, метрик и успешных проверок из HTML-прототипа.

## What Changes

- Заполнить «Подключение» серверными `connection.embed_code`, `connection.authorization`, `channel_id` и доменами; копировать код без преобразований и показывать результат операции.
- По согласованию с пользователем ссылка «Инструкция по встраиванию» открывает общий раздел «Документация» (`/docs`, с basename приложения), без новой статьи или внешнего URL.
- Заполнить «Обзор» сведениями регистрации, ответственными, статусом, датами и нагрузкой; различать `null` и ноль.
- Показать проверяемые факты из сохранённой карточки и явное отсутствие подтверждения уникальности доменов и прохождения песочницы. Не переносить постоянные зелёные отметки из прототипа.
- Сохранять последние успешно прочитанные сведения и черновик сценариев при ошибках повторного чтения; предоставить повтор загрузки.
- Кнопки публикации, lifecycle, конфигуратор и история не входят в change. Критерий MOS-913 о правах пользователя отложен до отдельного согласования модели доступа; две новые вкладки предоставляют чтение без операций записи бизнес-данных.

## Capabilities

### New Capabilities

- `surface-overview-connection`: серверные сведения обзора и подключения, точное копирование кода, переход в документацию, достоверный чек-лист и сохранение данных при ошибках чтения.

### Modified Capabilities

Нет. Существующие требования `surface-skill-selection`, `control-center-api-integration` и `control-center-shell` сохраняются; новая возможность заполняет предусмотренные точки расширения карточки.

## Impact

- `entities/surface`: расширение используемого DTO и runtime-валидации ответа `GET /api/control/api/surfaces/v1/surfaces/{surface_id}` по существующему `SurfaceDetailResponse`; сохранение полей при обновлении кеша после записи сценариев.
- `widgets/surface-details`: содержимое вкладок, обработка копирования и повторного чтения, component-тесты; регистрация и существующий редактор сценариев сохраняют поведение.
- Существующий маршрут `/docs` используется без изменения документации. Новые endpoints, зависимости и изменения опубликованного OpenAPI не требуются.
- HTML-прототип служит ориентиром компоновки; его фиктивный `data-token`, статические результаты проверок и локальные lifecycle-операции не переносятся.
