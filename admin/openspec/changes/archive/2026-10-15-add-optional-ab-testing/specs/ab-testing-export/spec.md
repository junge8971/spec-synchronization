## Purpose

Предоставить настоящий CSV-экспорт A/B-экспериментов с выбором поддержанных полей, сохранением полного отбора и честным представлением плоских сводных данных.

## ADDED Requirements

### Requirement: Full selection export

Экспорт списка SHALL передавать выбранные metadata export_fields в выбранном порядке и полный применённый search, выгружать весь отбор независимо от pagination в пределах export_max_rows (текущий предел 10000). Пустой выбор SHALL блокировать отправку. UI MUST NOT выгружать только загруженную страницу либо молча усекать результат.

#### Scenario: Export from second page

- **WHEN** на второй странице выбран экспорт name/surface_names/groups_count/status
- **THEN** CSV запрашивается для полного применённого отбора, а не локального массива строк

#### Scenario: Export limit exceeded

- **WHEN** сервер отклоняет превышение лимита
- **THEN** показано предложение сузить отбор без фиктивного полного или усечённого файла

### Requirement: Flat saved detail export

Экспорт карточки SHALL использовать сохранённый ID и fields без draft. Для новой записи экспорт SHALL быть недоступен с пояснением, для dirty — предупреждать о сохранённых данных. Выбор SHALL группироваться в «Основное», «Гипотеза и метрика», «Группы и распределение», «Поверхности», «Правила запуска» по поддержанным плоским колонкам. Group_distribution и surface_names SHALL быть обозначены сводными текстовыми колонками, не выгрузкой вложенных таблиц. Несуществующие groups/surfaces/sections payload MUST NOT отправляться; отдельный вложенный экспорт SHALL быть обозначен недоступным.

#### Scenario: Distribution export

- **WHEN** выбран экспорт групп
- **THEN** запрос содержит group_distribution и выбранный groups_count, UI поясняет текстовую сводку без обещания отдельных строк ab_group

#### Scenario: Dirty detail

- **WHEN** карточка имеет несохранённые изменения
- **THEN** экспорт предупреждает, что они не включены, и отправляет только ID/fields

### Requirement: Truthful file delivery

UI SHALL скачивать реальный ответ API через существующий file transport с безопасным именем, обработкой ошибок и освобождением временных ресурсов. Pending SHALL блокировать повторную отправку. Ошибки HTTP, схемы или скачивания MUST NOT показывать «Файл готов». Смена session owner SHALL исключать доставку старого файла в новый контекст.

#### Scenario: Failed export

- **WHEN** API вернул ошибку вместо CSV
- **THEN** файл и успешное уведомление отсутствуют, выбор полей сохранён для повтора
