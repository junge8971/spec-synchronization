## ADDED Requirements

### Requirement: Surface mock checks occupancy and returns confirmed rejection formats

Локальный API SHALL обслуживать `POST /api/control/api/surfaces/v1/surfaces/domains/check` для непустого списка доменных имён. Ответ `200` SHALL возвращать в `data.occupied_domains` только занятые адреса в нижнем регистре, без повторов и в алфавитном порядке. Занятость SHALL определяться по всем сохранённым поверхностям независимо от регистра, команды и статуса. Проверка MUST NOT менять состояние или возвращать сведения о владельцах и карточках.

POST создания SHALL повторно проверять домены. При конфликте ответ `409 DOMAIN_ALREADY_IN_USE` SHALL содержать в `errors[]` путь `/domains` и все конфликтующие адреса в `details.domains`. Ошибки валидации создания поверхности SHALL использовать `422 VALIDATION_ERROR` с `errors[]`, отсутствующий ответственный SHALL возвращать `422 FAILED` с путём к соответствующему полю. При таких отказах SHALL сохраняться прежнее состояние поверхностей и связей команд. Пустой `product_context` SHALL оставаться допустимым.

#### Scenario: Global partial domain check

- **WHEN** список содержит свободный домен, варианты регистра одного занятого домена и домен архивной поверхности другой команды
- **THEN** `200` возвращает только занятые домены по одному разу в нормализованном порядке, состояние не меняется

#### Scenario: Create rechecks previously free domains

- **WHEN** домены стали заняты после успешной предварительной проверки
- **THEN** `409` содержит все конфликтующие адреса, новая поверхность и связь команды отсутствуют

#### Scenario: Surface creation validation matches backend examples

- **WHEN** создание отклонено из-за структуры запроса или несуществующего ответственного
- **THEN** `422` возвращает код и ошибки полей в `errors[]`, новая поверхность и связь команды отсутствуют
