## Why

[Jira MOS-1255](https://task.mos-team.ru/browse/MOS-1255): [FE][Обратная связь] Реализовать интерактивный предпросмотр анкеты.

Нужна отдельная реализуемая поставка этой FE-подзадачи по обновлённому API и принятой границе прототипа. План, приёмка и выполнение учитываются отдельно от остальных задач MOS-1246.

## What Changes

- Живой preview семи типов, отдельные пробные ответы, required и сброс несовместимых ответов. Сетевого сбора ответов нет.
- Сохранить ограничения API, ввод при ошибках, доступность и действующую безопасность.

### Deferred scope

Реальные ответы не сохраняются и не отправляются. Preview не исполняет правила показа.

## Capabilities

### New Capabilities

- `feedback-preview`: Живой preview семи типов, отдельные пробные ответы, required и сброс несовместимых ответов. Сетевого сбора ответов нет.

### Modified Capabilities

Нет. Общие capabilities HTTP, permissions и MPMM сохраняются; scope соседних FE-подзадач сюда не переносится.

## Impact

Приватный preview редактора и локальное состояние пробных ответов.

Зависимости: [MOS-1254](../mos-1254-feedback-questions/proposal.md); [MOS-1251](../mos-1251-feedback-editor/proposal.md)

Нужны готовые вопросы MOS-1254 и foundation draft MOS-1251; финальная композиция MOS-1251 не блокирует preview.

Граница: UI по прототипу, операции по API, неподдержанное отложено. Исполнение правил и сбор реальных ответов пользователей не входят. Новые зависимости не требуются без отдельного обоснования. Это planning change: код приложения и Jira при разделении не меняются.
