## Purpose

Реализовать интерактивный предпросмотр анкеты в разделе обратной связи ЦАМ по опубликованному API, с отдельной приёмкой и сохранением ограничений первого этапа.

## ADDED Requirements

### Requirement: Isolated interactive preview

Preview SHALL немедленно отражать draft названия/описания, вопросов, вариантов, required и порядка. Семь типов SHALL иметь интерактивное представление: stars 1–5, scale/nps 0–10, emoji, да/нет, multi tags и текст. Пробные ответы SHALL быть отделены от карточки и MUST NOT отправляться на сервер. При пробной отправке обязательность SHALL проверяться с допустимыми 0/false; сообщение SHALL явно относиться к предпросмотру. Пропуск SHALL очищать пробные ответы. Удаление/смена типа/удаление варианта SHALL очищать несовместимые пробные ответы. Пустая анкета и неизвестный тип SHALL иметь явные состояния.

#### Scenario: Valid zero and negative boolean

- **WHEN** обязательная шкала имеет ответ 0, а обязательный boolean — «Нет»
- **THEN** пробная отправка считает оба ответа заполненными, не меняет draft и не вызывает API ответа пользователя

#### Scenario: Draft changes invalidate preview answers

- **WHEN** отвеченный вопрос удалён либо его тип изменён
- **THEN** несовместимый ответ удаляется из preview, оставшиеся вопросы отображаются в новом порядке

### Requirement: Accessible preview interactions

Область этой задачи — интерактивный preview и пробные ответы — SHALL поддерживать клавиатуру, доступные названия/ошибки, предсказуемый фокус и узкую компоновку. Приёмка SHALL проверять собственные элементы; реализация и приёмка соседних UI-возможностей MUST NOT требоваться для закрытия этой задачи сверх явно указанных зависимостей интеграции. Недоступные API MUST NOT имитироваться успешными заглушками.

#### Scenario: Keyboard and narrow layout within this task

- **WHEN** пользователь работает с элементами этой задачи клавиатурой на узком экране
- **THEN** действия и ошибки доступны, содержимое не перекрывает управляющие элементы, закрытие имеющихся диалогов возвращает фокус
