## Why

MOS-1015 требует конструктора отчётов по HTML-прототипу, тогда как `app/routes/reports.tsx` показывает заглушку. Пользователь согласовал реализацию возможного по существующим контрактам: можно подготовить полноценный локальный черновик настроек, но нельзя обещать серверный отчёт при отсутствии его API.

## What Changes

- Заменить заглушку страницей конструктора: период, включая «За всё время» и свой диапазон с «Применить»/«Сбросить»/закрытием без применения, поверхность, 24 колонки, сохранение порядка выбора и редактор одной группы условий AND/OR с каталогом 35 атрибутов прототипа.
- Подключить существующие API поверхностей и навыков только как справочники. Справочники без подтверждённого источника показывать недоступными, а не заполнять придуманными значениями.
- Валидировать локальный черновик, явно обозначать, что настройки ещё не применяются к данным и не сохраняются после перезагрузки.
- Показать четыре области показателей и предпросмотр в состоянии «Не поддерживается текущим API», без чисел, строк и запросов отчётности.
- Сохранить доступность и адаптивную компоновку прототипа, не переносить демонстрационные вычисления и ролевые ограничения.
- Поставить отдельным PR. Список шаблонов — MOS-916, CSV — MOS-919, подготовка сохранения/расписания — MOS-1016; их элементы не реализуются в этом PR.

### Contract boundary

`docs/api/contracts/reports.md` и `dialogs.md` явно сообщают об отсутствии операций; в `openapi.json` схем отчётности нет. Имена методов и прежние 18 полей из `docs/tasks/control-center/frontend-backlog.md` — исторический анализ, не основание писать HTTP-клиент. Серверный preview, показатели, wire-коды колонок и advanced selection отложены до согласования контракта и обновления плана. Завершение этого change означает UI-поставку, а не полную приёмку MOS-1015. Матрица покрытия и проверяемые критерии отложенного продолжения находятся в `design.md` (C01–C12, B15.1–B15.5); статус «Сейчас» означает включение в план, а не завершённую реализацию.

## Capabilities

### New Capabilities

- `report-constructor-draft`: Настройки локального черновика отчёта, каталог колонок и честное состояние недоступных результатов.
- `dialog-selection-draft`: Переиспользуемый редактор локальных условий диалогов без выполнения отбора и без придуманного серверного DTO.

### Modified Capabilities

Нет. Требования существующих transport, shell и API integration сохраняются; доступная сейчас конфигурация черновика не является применённым серверным фильтром.

## Impact

- `app/routes/reports.tsx`, новый `app/pages/reports`, `app/widgets/report-constructor`, `app/features/dialog-selection`; публичные API соответствующих слайсов.
- Переиспользование/узкое расширение справочников `app/entities/surface` и `app/entities/skill`, существующих React Query, React Hook Form, Zod и UI-компонентов; без новых зависимостей.
- Unit/component-проверки локальной валидации, доступности, справочников и отсутствия неподтверждённых запросов. Generated API, mock endpoints отчётности и файловый транспорт не меняются.
