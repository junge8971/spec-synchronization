## Purpose

Предотвратить отправку конфликтующих обучающих фраз посредством серверной проверки актуального набора во всём допустимом реестре навыков.

## ADDED Requirements

### Requirement: Global server conflict check

При наличии согласованного API проверка SHALL выполняться сервером по всему допустимому реестру с согласованной нормализацией. Локальное сравнение загруженной страницы MUST NOT заменять глобальный результат. Без API SHALL отображаться unavailable без имитации проверки.

#### Scenario: Conflict outside current page

- **WHEN** сервер обнаруживает совпадение с навыком, отсутствующим на загруженной странице
- **THEN** совпадение отображается и влияет на отправку так же, как конфликт с видимым навыком

### Requirement: Exact and semantic conflict handling

UI SHALL показывать фразу, тип конфликта, близость, навык и домен в объёме разрешённого серверного ответа. Точное совпадение SHALL блокировать согласованную контрактом отправку; смысловая близость SHALL предупреждать без самостоятельного запрета этой отправки.

#### Scenario: Exact match

- **WHEN** актуальный результат содержит точное совпадение
- **THEN** отправка заблокирована и показана причина

#### Scenario: Semantic proximity

- **WHEN** актуальный результат содержит только смысловую близость
- **THEN** показано предупреждение с серверной близостью, но оно само по себе не блокирует отправку

#### Scenario: Restricted conflict details

- **WHEN** сервер сообщает конфликт без раскрытия названия или ID чужого навыка
- **THEN** показано нейтральное описание, а клиент не пытается самостоятельно получить скрытые сведения

### Requirement: Check result freshness

Результат SHALL относиться к текущему набору фраз/версии. Изменённый ввод, pending, ошибка или устаревший результат MUST NOT считаться успешной проверкой и разрешать требующую проверки отправку. Серверная команда SHALL повторно обеспечивать согласованные ограничения при отправке.

#### Scenario: Late response

- **WHEN** пользователь изменил фразы, а затем пришёл успешный ответ для предыдущего набора
- **THEN** новый набор остаётся непроверенным и отправка не разблокируется старым ответом

#### Scenario: Network failure

- **WHEN** запрос проверки завершился ошибкой
- **THEN** видны ошибка и повтор, а не сообщение «Конфликтов нет»
