## Purpose

Предоставить read-only эксплуатационные сведения навыка: ответственных, плановые работы, внешние зависимости и инциденты из источника.

## ADDED Requirements

### Requirement: Operational contacts and maintenance

При наличии согласованного API UI SHALL показывать владельца, технических представителей, заместителей, контакты сопровождения и плановые работы с периодом и причиной. Неизвестные контакты MUST NOT выводиться из состава команды по предположению.

#### Scenario: Backup not assigned

- **WHEN** сервер сообщает отсутствие заместителя
- **THEN** показано «Не назначен», а не подставлен основной контакт

#### Scenario: Scheduled maintenance

- **WHEN** источник возвращает плановые работы
- **THEN** показаны период с однозначным временем и причина работ

### Requirement: External dependencies and incidents

UI SHALL показывать внешние системы, ответственных, доступность и время проверки. Инциденты SHALL содержать уровень, событие, причину, исполнителя, срок, состояние, идентификатор и безопасную ссылку внешнего источника согласно ответу.

#### Scenario: Read incident source

- **WHEN** пользователь открывает блок инцидентов
- **THEN** показаны серверные события с внешними идентификаторами и ссылками, не локально сгенерированная история

#### Scenario: Unsafe source URL

- **WHEN** источник вернул ссылку с исполняемой или иной неподдержанной схемой
- **THEN** UI не создаёт исполняемую ссылку, сохраняя возможность прочитать безопасные сведения об инциденте

### Requirement: Read-only and honest source states

Блоки SHALL оставаться read-only без подтверждения уведомлений и редактирования postmortem. UI SHALL различать пустой список, ошибку, отсутствие подключения и отсутствие API; сбой одного блока MUST NOT маскироваться как отсутствие инцидентов и скрывать остальные сведения.

#### Scenario: Empty source

- **WHEN** сервер успешно возвращает пустой список инцидентов
- **THEN** показано отсутствие записей без действий редактирования или подтверждения

#### Scenario: Source failure

- **WHEN** чтение инцидентов завершилось ошибкой
- **THEN** блок предлагает повтор, другие загруженные сведения остаются доступны, сообщение «Инцидентов не было» не показывается
