Название модуля
Аутентификация и сеанс
Название задач
Создание функции синхронного обмена данными аутентификации пользователя с СУДИР;
Создание функции хранения данных пользовательских сеансов;
Создание функции завершения пользовательской сессии;
Создание функции автоматического блокирования пользовательской сессии по истечении времени бездействия;
Создание функции хранения данных профилей доступа пользователей;
Создание функции хранения данных связи профиля пользователя с учетной записью СУДИР;
Создание функции получения данных учетной записи пользователя от СУДИР;

| 2. | Реализовать требования к паролю: | СУДИР

| 2.4. | задание срока смены паролей; |

| 2.5. | блокировка учетной записи пользователя в случае достижения установленного максимального количества неуспешных попыток аутентификации (от 5 до 30 минут); |
СУДИР

СУДИР
По парольной политике – алфавит пароля не менее 70 символов, длина пароля не менее 8 символов (не менее 12 символов для привилегированных пользователей).
Пароль должен включать в себя символы не менее трех различных групп из перечисленных:
- заглавные прописные буквы;
- строчные буквы;
- арабские цифры;
- специальные символы
| 2.7. | задание минимального количества измененных символов при создании новых паролей; |
СУДИР
По парольной политике – новое значение пароля должно отличаться не менее чем в 5 символах
| 2.8. | задание максимального времени действия пароля; | СУДИР
| 2.9. | задание минимального времени действия пароля; | СУДИР
| 2.10. | запрет на использование пользователями определенного оператором числа последних использованных паролей при создании новых паролей; |
СУДИР
По парольной политике – новое значение пароля не должно совпадать с 5 предыдущими значениями паролей для данного пользователя
| 2.11. | блокирование (прекращение действия) и замена утерянных, скомпрометированных средств аутентификации (паролей). | СУДИР
| 2.12. | отображение символов пароля как */• в поле ввода пароля | СУДИР
