Название задачи
Обеспечить поиск, фильтрацию, просмотр и экспорт диалогов пользователей с ассистентом для анализа качества, разбора инцидентов и выявления проблемных зон.
Контекст
Диалоги - это основной источник данных о качестве работы ассистента и операторов. Аналитики качества, владельцы навыков и клиентский сервис используют диалоги для разбора обращений, выявления сбоев, оценки качества ответов и формирования отчётов. Ранее диалоги были разрознены по разным системам (логи, старый чат). Админка предоставляет единый интерфейс для поиска, фильтрации, просмотра и экспорта диалогов.
Проблематика
| Проблема | Описание | Влияние на команды | Решение
| Разрозненные данные | Диалоги хранятся в разных системах. | Сложно собрать полную картину по обращению. | Единый реестр диалогов.
| Сложный поиск | Нет возможности искать по тексту, ID, атрибутам. | Аналитики тратят часы на поиск нужного диалога. | Полнотекстовый поиск и фильтры.
| Нет контекста | Не видно полной переписки и таймлайна. | Сложно понять, почему произошёл сбой. | Карточка диалога с перепиской и таймлайном.
| Нет экспорта | Нельзя выгрузить диалоги для внешнего анализа. | Отчёты собираются вручную. | Экспорт в CSV (и XLSX в перспективе).

User Story
Как аналитик качества
Я хочу быстро находить и разбирать проблемные диалоги, видеть полную переписку, таймлайн и атрибуты сессии, чтобы выявлять причины сбоев и оценивать качество ответов ассистента и операторов.
Как владелец навыка
Я хочу видеть диалоги с участием моего навыка, чтобы понимать, как пользователи взаимодействуют с ним, и улучшать его.
Как клиентский сервис
Я хочу просматривать диалоги целиком и экспортировать их для внешнего разбора.

Функциональные требования
MUST
Реестр диалогов: таблица с колонками: тип (сбой/оператор/бот), дата, тема, канал, оценка, длительность. Фильтры: период (сегодня/неделя/месяц/произвольный), канал, навык. Поиск по тексту, chatId, sessionId, ssoId. Сортировка по всем колонкам.
Карточка диалога:
Переписка: сообщения с авторами (пользователь, ассистент, оператор), временем, текстом. Для владельца навыка сообщения его навыка подсвечены.
Таймлайн: временная шкала с задержками между сообщениями.
Атрибуты: chatId, sessionId, ssoId, канал, поверхность, устройство, URL, тема, категории, тип (бот/оператор), причина завершения, кто завершил, длительность, оценка оператора, комментарий.
Экспорт: выгрузка отдельного диалога в CSV; массовый экспорт отмеченных диалогов с выбором набора полей.
Отметка диалогов: чекбоксы для отметки диалогов в списке.
SHOULD
Подсветка сообщений навыка для владельца.
Фильтр по признаку «сбой».
Экспорт в XLSX (в дополнение к CSV).
Предпросмотр диалога без открытия карточки.
COULD
Автоматическая разметка диалогов (темы, категории) через ML.
Интеграция с Writer для получения дополнительных данных.
WON'T
Редактирование диалогов.
Ручная разметка диалогов (только просмотр и экспорт).
Нефункциональные требования
Поиск по тексту - до 2 секунд.
Загрузка карточки диалога - до 1 секунды.
Доступ к диалогам ограничен ролями (владелец видит только свои навыки).
Ограничения
НПА: соблюдение 152-ФЗ - персональные данные в диалогах доступны только авторизованным сотрудникам.
Технические: данные хранятся в ядре ЕСК, админка получает их по API.
ИБ: доступ к диалогам только через авторизацию, все действия фиксируются в аудите.
Этапы реализации
MVP (ноябрь 2026): реестр диалогов с базовыми фильтрами (период, канал), поиск по тексту, карточка диалога (переписка, атрибуты), экспорт отдельного диалога.
Этап 2 (декабрь 2026): фильтры по навыку, по сбоям, массовый экспорт, таймлайн, подсветка сообщений навыка.
Этап 3 (2027): интеграция с Writer, автоматическая разметка, экспорт в XLSX.
Пользовательский путь (аналитик качества)
Переходит в «Диалоги» → видит список диалогов.
Применяет фильтры (период, канал) и выполняет поиск по тексту или ID.
Находит нужный диалог → кликает по нему.
Видит карточку диалога: переписку, таймлайн, атрибуты.
Анализирует диалог → при необходимости экспортирует его или отмечает для массовой выгрузки.
Нажимает «Выгрузить отмеченные» → скачивает CSV-файл.
