Название задачи
Обеспечить визуализацию ключевых показателей качества и эксплуатации ассистента в виде настраиваемой доски виджетов для оперативного мониторинга и принятия решений.
Контекст
Дашборд - это главный инструмент для руководства, аналитиков и владельцев навыков/поверхностей для быстрой оценки состояния системы. Он агрегирует данные из диалогов и показывает KPI (DAU, оценки, доля переходов на оператора) и диагностические метрики (распределение по доменам, динамика, точки отказа). Дашборд настраивается под роль пользователя.

| Данные устаревают | Показатели пересчитываются редко. | Решения принимаются на устаревших данных. | Актуализация при смене фильтров.
User Story
Как руководитель
Я хочу видеть сводную картину по ассистенту: количество диалогов, оценки, долю переходов на оператора и динамику, чтобы быстро оценивать состояние системы и принимать решения.
Как аналитик качества
Я хочу настраивать дашборд под свои задачи, добавлять нужные виджеты и видеть актуальные данные, чтобы оперативно выявлять проблемные зоны.
Как владелец навыка
Я хочу видеть показатели по своим навыкам (количество обращений, оценки, ошибки), чтобы понимать, как они работают.

Функциональные требования
MUST
Доска виджетов: сетка виджетов, которые можно добавлять/удалять/перетаскивать.
Типы виджетов:
KPI: уникальные пользователи, DAU, MAU, оценки, технические отказы, время ответа, доля переходов на оператора, решено без оператора, ошибки NLP, завершённые диалоги.
Диагностические: средняя продолжительность сессии, вернувшиеся пользователи, частота использования, распределение оценок оператора, распределение по доменам, точки отказа, процент низких оценок, доля оставивших оценку.
Фильтр по периоду: сегодня/неделя/месяц, канал.
Каталог виджетов: список всех доступных виджетов с отметкой о доступности (доступен/требует разметки/требует данных из Writer).
Ролевая настройка: владельцы навыков видят только метрики по своим навыкам; владельцы поверхностей - по своей поверхности.
SHOULD
Предпросмотр виджета при добавлении.
Автообновление данных при смене фильтров.
Экспорт дашборда в PNG/PDF для презентаций.
COULD
Интеграция с внешними источниками данных.
Пользовательские виджеты с произвольными запросами.
WON'T
Полноценный BI-инструмент (только предустановленные виджеты).
Редактирование данных на дашборде.
Нефункциональные требования
Загрузка дашборда - до 3 секунд.
Обновление при смене фильтра - до 2 секунд.
Данные рассчитываются по выборке диалогов за выбранный период.
Ограничения
Технические: данные агрегируются из ядра ЕСК, часть метрик требует разметки навыков или интеграции с Writer.
ИБ: доступ к данным ограничен ролями.
Этапы реализации
MVP (ноябрь 2026): базовая доска с KPI-виджетами (уникальные пользователи, DAU, оценки, отказы, время ответа), фильтр по периоду.
Этап 2 (декабрь 2026): диагностические виджеты (распределение, динамика), каталог виджетов, настройка доски (добавление/удаление).
Этап 3 (2027): полная интеграция с Writer, разметка навыков, недоступные виджеты становятся доступными.
Пользовательский путь (аналитик качества)
Переходит в «Дашборд» → видит доску с виджетами.
Выбирает период → виджеты пересчитываются.
Нажимает «Настроить доску» → удаляет ненужные виджеты, перетаскивает оставшиеся, добавляет новые из каталога.
Сохраняет настройки.
Кликает по виджету → видит детализацию.
Использует дашборд для оперативного мониторинга и подготовки отчётов.
