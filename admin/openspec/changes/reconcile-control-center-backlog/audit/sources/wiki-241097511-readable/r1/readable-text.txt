Общая информация
Версия контракта: v1.0.
Тип изменения:
новые методы просмотра и ведения доменов, создания навыка и изменения его карточки.
Назначение: предоставить административному интерфейсу API для работы с реестром доменов и каталогом навыков.
Базовый путь: /api/control/api/skills/v1.
Методы принадлежат модулю навыков сервиса tsam-assistant-management-service-back.
Аутентификация: прикладная сессия в защищённой HttpOnly cookie.
Формат данных
API использует application/json в кодировке UTF-8. Даты передаются в формате RFC 3339, в примерах указан UTC. Имена полей записываются в snake_case.
Общие заголовки
| Заголовок | Обязательность | Описание
| X-Request-Id | Нет в запросе, да в ответе | UUID запроса. Backend создаёт значение, если клиент его не передал
| Idempotency-Key | Да для POST и PATCH | UUID логической изменяющей операции
Общая модель ответа
Все JSON-методы используют envelope:
{
"code": "SUCCESS",
"data": {},
"message": "",
"errors": []
}
| Поле | Тип | Описание
| code | string | SUCCESS при успехе или машиночитаемый код ошибки
| data | object или null | Результат операции. При ошибке обычно null
| message | string | Краткое безопасное описание результата
| errors | array of objects | Детали ошибок. При успехе пустой массив
Элемент errors:
{
"field": "/name",
"code": "REQUIRED",
"message": "Поле обязательно"
}
1. Цель задачи
Предоставить административному интерфейсу API для:
просмотра, поиска, фильтрации и сортировки доменов;
получения карточки домена;
создания и изменения домена;
просмотра, поиска, фильтрации и сортировки навыков;
получения карточки навыка;
создания навыка;
изменения карточки навыка;
защиты изменяющих запросов от повторного выполнения и конкурентной записи.
1.1 Модель домена
{
"id": "01991b3a-7c10-7000-8000-000000000041",
"name": "Городские сервисы",
"description": "Навыки городских услуг и обращений",
"owner": "ДИТ, управление городских сервисов",
"team": {
"id": "f24f0af5-e3ea-45e7-856d-b950fb94bd03",
"name": "Городские сервисы"
},
"api_url": "https://skills.example.internal",
"zones": ["authenticated", "anonymous"],
"skills_count": 12,
"version": 3,
"created_at": "2026-09-01T09:00:00.000Z",
"updated_at": "2026-09-07T10:15:00.000Z"
}
| Поле | Тип | Обязательность | Описание
| id | UUIDv7 | Да | Стабильный идентификатор домена
| name | string | Да | Название домена
| description | string | Да | Назначение домена
| owner | string | Да | Подразделение ДИТ
| team | object | Да | Краткие сведения о команде в формате контракта управления командами
| api_url | string | Да | Базовый адрес API домена
| zones | array[Zone] | Да | Одна или несколько рабочих зон
| skills_count | integer | Да в ответе списка | Число навыков домена, не меньше 0
| version | integer | Да | Версия для optimistic locking
| created_at | string | Да | RFC 3339, UTC
| updated_at | string | Да | RFC 3339, UTC
Допустимые значения zones в текущей версии:
authenticated, навык доступен авторизованному пользователю;
anonymous, навык доступен без пользовательской авторизации.
Zone является enum. Массив zones может содержать только перечисленные значения.
Термин и окончательный справочник зон требуют подтверждения в открытых вопросах.
team.id и team.name совпадают с полями карточки команды. Идентификатор команды берётся из контракта управления командами.
1.2 Ограничения домена
| Поле | Предлагаемое ограничение
| name | После trim от 1 до 100 символов
| description | После trim от 1 до 2000 символов
| owner | После trim от 1 до 200 символов
| team_id | Команда из области доступа сотрудника
| api_url | Абсолютный HTTPS URL без query, fragment и userinfo
| zones | От 1 до 2 уникальных значений из справочника
Предлагаемая нормализация уникальности:
Имя сравнивается после trim, схлопывания повторных пробелов и приведения к нижнему регистру.
api_url сравнивается после приведения host к нижнему регистру, удаления стандартного порта и завершающего /.
И имя, и api_url уникальны в системе.
Эти правила не подтверждены источниками и вынесены в открытых вопросах.

1.4 Ограничения навыка
| Поле | Предлагаемое ограничение
| name | После trim от 1 до 120 символов
| service_id | От 3 до 100 символов. Предлагаемый формат: латинские строчные буквы и цифры, части разделяются точкой, подчёркиванием или дефисом. Пример из прототипа: gkh.water
| purpose | После trim от 1 до 2000 символов
| expected_result | После trim от 1 до 2000 символов
| description | До 5000 символов
| limitations | До 5000 символов
| comments | До 5000 символов
| related_materials | До 20 элементов
| related_materials[].title | От 1 до 200 символов
| related_materials[].url | Абсолютный HTTPS URL, до 2000 символов
| connection.endpoint | Абсолютный HTTPS URL без userinfo и fragment
| connection.parameters | До 100 элементов, уникальный key
Значения ограничений являются предложением для ревью.
1.5 Подключение навыка
| Поле | Тип | Обязательность | Описание
| endpoint | string | Нет | Адрес реализации навыка
| contract_version | string | Нет | Версия стандартного контракта навыка ЦАМ
| auth_required | boolean | Да при наличии connection | Требуется ли транспортная авторизация
| auth_type | string или null | При auth_required = true | Предлагаемое значение transport_token
| parameters | array | Нет | Описания параметров, которые может настраивать поверхность
SurfaceParameter:
| Поле | Тип | Обязательность | Описание
| key | string | Да | Стабильный программный ключ
| title | string | Да | Название в интерфейсе
| type | string | Да | В текущем контракте поверхностей поддерживается select
| required | boolean | Да | Обязателен ли параметр для поверхности
| default | string, integer или null | Нет | Значение по умолчанию
| options | array of strings | Для select | Допустимые значения
Форма key, title, type, required, default, options совпадает с методом GET /available-skills из контракта управления поверхностями. Это устраняет отдельное преобразование названий полей между двумя модулями.
Секреты и значения транспортных токенов в модели Skill не возвращаются. Их выдача и ротация требуют отдельного защищённого контракта.
2. Методы API
2.1 Получить список доменов
GET /api/control/api/skills/v1/domains
Доступ: требуется действующая прикладная сессия. Точные permissions и области видимости определяются отдельным авторизационным контрактом.
Параметры запроса
| Параметр | Тип | Обязательность | Описание
| query | string | Нет | Поиск по названию, описанию и API-адресу. От 2 до 100 символов
| team_id | string | Нет | Фильтр по команде, если она входит в область доступа
| owner_user_id | UUID | Нет | Фильтр по владельцу
| zone | Zone | Нет | Фильтр по рабочей зоне
| sort | string | Нет | Поля через запятую. Префикс - задаёт убывание. Допустимы name, created_at, updated_at. По умолчанию name,id
| limit | integer | Нет | Число записей от 1 до 100. По умолчанию 20
| offset | integer | Нет | Число пропускаемых записей. По умолчанию 0
Пример запроса
GET /api/control/api/skills/v1/domains?query=город&zone=authenticated&sort=name&limit=20&offset=0 HTTP/1.1
Успешный ответ
HTTP 200 OK

"items": [
{

"owner": "ДИТ, управление городских сервисов",
"team": {
"id": "f24f0af5-e3ea-45e7-856d-b950fb94bd03",

"created_at": "2026-09-01T09:00:00.000Z",

"limit": 20,
"offset": 0,
"current_page": 1,
"total_items": 1,
"total_pages": 1
}
},
"message": "",
"errors": []
}
Поля пагинации
| Поле | Тип | Описание
| limit | integer | Запрошенное число записей на странице
| offset | integer | Число пропущенных записей
| current_page | integer | Номер текущей страницы, начиная с 1
| total_items | integer | Общее число записей с учётом фильтров
| total_pages | integer | Общее число страниц при текущем limit
Пустой реестр возвращается с HTTP 200, пустым массивом items, значением total_items = 0 и total_pages = 0.
Ошибки
400 INVALID_ARGUMENT, параметры поиска, фильтра или сортировки невалидны.
401 UNAUTHENTICATED, сессия отсутствует, истекла или отозвана.
403 FORBIDDEN, операция запрещена внешней проверкой доступа.

2.3 Создать домен
POST /api/control/api/skills/v1/domains
Доступ: требуется действующая прикладная сессия. Правило доступности team_id определяется отдельным авторизационным контрактом.
Заголовки
Заголовок Idempotency-Key обязателен.
Тело запроса
{
"name": "Городские сервисы",
"description": "Навыки городских услуг и обращений",
"owner": "ДИТ, управление городских сервисов",
"team_id": "f24f0af5-e3ea-45e7-856d-b950fb94bd03",
"api_url": "https://skills.example.internal",
"zones": ["authenticated", "anonymous"]
}
Все поля обязательны.
Успешный ответ
HTTP 201 Created. В data возвращается полная модель Domain.
{
"code": "SUCCESS",
"data": {
"id": "01991b3a-7c10-7000-8000-000000000041",
"name": "Городские сервисы",
"description": "Навыки городских услуг и обращений",
"owner": "ДИТ, управление городских сервисов",

"id": "f24f0af5-e3ea-45e7-856d-b950fb94bd03",
"name": "Городские сервисы"
},
"api_url": "https://skills.example.internal",
"zones": ["authenticated", "anonymous"],
"skills_count": 0,
"version": 1,
"created_at": "2026-09-07T12:00:00.000Z",
"updated_at": "2026-09-07T12:00:00.000Z"
},
"message": "Домен создан",
"errors": []
}
Ошибки
400 INVALID_ARGUMENT, передан некорректный JSON.
422 VALIDATION_ERROR, поля запроса не прошли проверку.
401 UNAUTHENTICATED.
403 FORBIDDEN, операция запрещена внешней проверкой доступа.
404 NOT_FOUND, команда не найдена либо недоступна.
409 DOMAIN_NAME_ALREADY_EXISTS, нормализованное имя занято.

]
}
2.4 Изменить домен
PATCH /api/control/api/skills/v1/domains/{domain_id}
Доступ: требуется действующая прикладная сессия. Правила изменения владельца и команды определяются отдельным авторизационным контрактом.
Заголовки
Заголовок Idempotency-Key обязателен.
Параметры пути
| Параметр | Тип | Описание
| domain_id | UUIDv7 | Идентификатор домена
Тело запроса
Тело запроса содержит только изменяемые поля и обязательный expected_version:
{
"expected_version": 3,
"description": "Навыки городских услуг, обращений и записи",
"owner": "Департамент городских сервисов",
"zones": ["authenticated"]
}
Изменяемые поля
name;
description;
owner;
team_id;
api_url;
zones.
Успешный ответ
HTTP 200 OK. Возвращается полная модель Domain с увеличенной версией.
Ошибки
Ошибки совпадают с методом создания, дополнительно:
404 NOT_FOUND, домен не найден или недоступен.
409 VERSION_CONFLICT.
Пример конфликта версии:
{
"code": "VERSION_CONFLICT",
"data": null,
"message": "Домен был изменён другим пользователем",
"errors": [
{
"code": "VERSION_CONFLICT",
"message": "Ожидаемая версия домена не совпадает с текущей.",
"details": {
"id": "01991b3a-7c10-7000-8000-000000000041",
"expected_version": 3,
"current_version": 4
}
}
]
}
2.5 Получить список навыков
GET /api/control/api/skills/v1/skills
Доступ: требуется действующая прикладная сессия. Ограничение списка по области видимости определяется отдельным авторизационным контрактом.
Параметры запроса
| Параметр | Тип | Обязательность | Описание
| query | string | Нет | Поиск по name, id и service_id. От 2 до 100 символов
| domain_id | string | Нет | Фильтр по домену
| team_id | string | Нет | Фильтр по команде
| sort | string | Нет | Поле и направление сортировки
| limit | integer | Нет | Число записей от 1 до 100. По умолчанию 20
| offset | integer | Нет | Число пропускаемых записей. По умолчанию 0
Допустимая сортировка текущей версии:
name, -name;
domain_name, -domain_name;
created_at, -created_at;
updated_at, -updated_at.
По умолчанию: -updated_at,id.
Пример запроса
GET /api/control/api/skills/v1/skills?query=оплата&domain_id=01991b3a-7c10-7000-8000-000000000041&sort=-updated_at&limit=20&offset=0 HTTP/1.1
Успешный ответ

2.9 Обработка конкурентных и повторных команд
Версия объекта
Каждый домен и навык имеет целочисленное поле version.
При создании backend устанавливает version = 1.
PATCH обязан содержать expected_version.
Изменение выполняется только при совпадении expected_version с текущей версией.
После успешного изменения backend увеличивает version на 1.
При несовпадении возвращается 409 VERSION_CONFLICT и текущая версия объекта.
Идемпотентность
POST и PATCH домена или навыка требуют Idempotency-Key.
Один ключ относится к сочетанию HTTP-метода, URI и тела запроса в контексте текущего пользователя.
Повтор с тем же ключом и тем же телом возвращает исходный результат без повторного изменения данных.
Повтор с тем же ключом и другим телом возвращает 409 IDEMPOTENCY_KEY_REUSED.
Повтор возвращает исходный HTTP-статус и тело ответа.
Срок хранения результата не задаётся этим контрактом и должен определяться общей реализацией идемпотентности сервиса.
2.10 Формат ошибок
| HTTP | code | Условие
| 400 | INVALID_ARGUMENT | Некорректный JSON, параметр пути или query
| 401 | UNAUTHENTICATED | Сессия отсутствует, истекла или отозвана
| 403 | FORBIDDEN | Операция запрещена внешней проверкой доступа
| 404 | NOT_FOUND | Запрошенный или связанный объект не найден либо недоступен
| 409 | DOMAIN_NAME_ALREADY_EXISTS | Имя домена не уникально
| 409 | DOMAIN_API_URL_ALREADY_EXISTS | API-адрес домена не уникален
| 409 | SKILL_SERVICE_ID_ALREADY_EXISTS | service_id навыка не уникален
| 409 | VERSION_CONFLICT | Версия объекта изменилась
| 409 | IDEMPOTENCY_KEY_REUSED | Ключ изменяющей операции использован с другим запросом
| 409 | DOMAIN_TEAM_MISMATCH | Домен не принадлежит команде навыка
| 422 | VALIDATION_ERROR | Поля тела не прошли бизнес-проверки или ограничения формата
| 500 | INTERNAL_ERROR | Внутренняя ошибка
Пример общей ошибки доступа:
{
"code": "FORBIDDEN",
"data": null,
"message": "Недостаточно прав для выполнения операции",
"errors": []
}
Пример ошибки валидации:
{
"code": "VALIDATION_ERROR",
"data": null,
"message": "Запрос не прошёл валидацию",
"errors": [
{
"field": "/name",
"code": "REQUIRED",
"message": "Поле обязательно"
}
]
}
