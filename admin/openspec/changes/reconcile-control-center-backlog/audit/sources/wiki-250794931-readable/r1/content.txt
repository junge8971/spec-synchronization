Что это даёт бизнесу
В каждом списке разделов («Обратная связь», «База знаний», «Шаблоны ответов», «A/B эксперименты», «API», «Справочники», «Состояние системы») есть единый механизм поиска и отбора. Он позволяет быстро находить нужные записи, сохранять часто используемые наборы фильтров под понятным именем и возвращаться к ним в один клик - без повторной настройки.
Из чего состоит фильтрация
Механизм включает четыре независимых инструмента. Они работают одновременно: чем больше инструментов задействовано, тем точнее выборка.
1. Поиск по строке
Поле поиска в верхней части списка. Введите минимум два символа - система ищет совпадения по:
названию записи,
служебному коду,
описанию,
тегам,
связанным сущностям (навыки, категории, аудитория).
Работает как нечёткое совпадение: ищет подстроку без учёта регистра.
2. Фильтр-список с одним выбором
Выпадающий список (например, «Категория», «Тип шаблона», «Состояние»). Позволяет оставить в таблице только записи с одним конкретным значением. Выбор одного пункта автоматически снимает предыдущий.
3. Мультиселект-фильтр
Выпадающий список с чекбоксами (например, «Все статусы», «Все типы», «Все разделы»). Позволяет выбрать сразу несколько значений. В шапке кнопки отображается либо «Все ...» (если ничего не выбрано), либо имя одного выбранного пункта, либо «Выбрано: N».
У каждого пункта справа серым моноширинным шрифтом показан служебный код - это помогает не путать похожие названия.
4. Расширенный конструктор условий «⚙ Условия»
Самый гибкий инструмент. Открывается по кнопке «⚙ Условия» в строке фильтров. Позволяет собрать произвольное логическое выражение из нескольких условий.
Как устроен:
Тип соединения - «И» (все условия одновременно) или «ИЛИ» (хотя бы одно).
Условие - тройка «поле + оператор + значение».
Поле выбирается из списка доступных для раздела.
Оператор зависит от типа поля:
для текста - содержит / не содержит / равно / не равно / начинается с / заканчивается на / пусто / не пусто;
для справочных значений - входит в / не входит в (с чипсами);
для чисел - равно / больше / больше или равно / меньше / меньше или равно / между.
Значение вводится вручную, выбирается из чипсов или указывается диапазоном «от–до».
Что можно делать:
Добавлять условия кнопкой «+ Добавить условие».
Удалять любое условие крестиком справа.
Очистить все условия сразу кнопкой «Очистить».
Применить отбор кнопкой «Применить отбор» - только после этого условия вступают в силу.
Важно: пока вы не нажали «Применить отбор», изменения в конструкторе не влияют на таблицу.
После применения:
на кнопке «⚙ Условия» появляется красный бейдж с числом активных условий;
под строкой фильтров появляется панель с описанием применённых условий и кнопкой «Сбросить всё».
5. Кнопка «Сбросить»
Появляется, как только хотя бы один из инструментов активен. Одним нажатием очищает поиск, все выпадающие списки, мультиселекты и расширенные условия.
Как сохранять и переиспользовать фильтры
Справа от кнопки сброса есть меню «⋮» (три точки). Оно позволяет:
Сохранить текущий фильтр
Настройте отбор любым удобным способом (поиск, списки, мультиселекты, расширенные условия).
Нажмите «⋮» → «Сохранить текущий фильтр».
Введите понятное имя - например, «Активные ЖКХ-опросники».
Фильтр сохранится и появится в списке под меню.
Что сохраняется вместе с фильтром:
текст поиска,
все выбранные значения в мультиселектах,
все расширенные условия и логика их соединения (И / ИЛИ),
служебная информация о разделе и авторе.
Если ввести имя, которое уже есть, - старый фильтр перезапишется новым.
Применить сохранённый фильтр
В меню «⋮» в разделе «Сохранённые фильтры» появится список ваших фильтров. Клик по названию - все настройки мгновенно подставятся в интерфейс и таблица обновится.
Удалить сохранённый фильтр
Рядом с каждым фильтром в списке - крестик. Клик удаляет фильтр без подтверждения.
Скопировать ссылку на отбор
Пункт «Скопировать ссылку на отбор» формирует URL со всеми текущими параметрами и копирует его в буфер обмена. Такой ссылкой можно поделиться с коллегой - при открытии у него применятся те же фильтры.
Рекомендации по работе
Сохраняйте фильтры с говорящими именами - по ним удобно ориентироваться через месяц.
Имена уникальны в рамках раздела: одинаковое имя перезаписывает старый фильтр.
Каждый пользователь видит только свои сохранённые фильтры.
Расширенные условия не применяются, пока не нажата кнопка «Применить отбор».
«Сбросить всё» в панели применённых условий очищает только расширенные условия; кнопка «Сбросить» в строке фильтров - всё сразу.

Структура таблиц
| Поле | Тип | Ограничения | Описание
| id | uuid | NOT NULL DEFAULT gen_random_uuid(), PRIMARY KEY | Уникальный идентификатор записи.
| user_id | character varying | NOT NULL, collation pg_catalog."default" | Идентификатор пользователя - владельца фильтра. Длина не ограничена.
| name | character varying(150) | NOT NULL, collation pg_catalog."default" | Отображаемое имя сохранённого фильтра. Максимум 150 символов.
| search | jsonb | NOT NULL | Сохранённые условия фильтра/поиска в формате JSONB.
| created_at | timestamp without time zone | NOT NULL DEFAULT now() | Дата и время создания записи.
| updated_at | timestamp without time zone | NOT NULL DEFAULT now() | Дата и время последнего обновления записи.
