| Сущность | Описание

| ActionAudit | Журнал действий над объектами (CRUD, смена статусов)
| Module | Модуль платформы (рубильник)

Подробное описание сущностей
Административная панель
User (Пользователь)
Назначение – учётная запись пользователя административной панели.
| Поле | Тип | Обязательность | Описание
| id | string | да | Уникальный идентификатор
| sudir_uuid | string | да | Уникальный идентификатор в СУДИР
| full_name | string | да | ФИО
| email | string | нет | Электронная почта
| team_id | string | нет | Логическая ссылка на Team (без FK) – указывает, в какой команде состоит пользователь
| is_active | boolean | да | Активен / не заблокирован
| last_login_at | datetime | нет | Дата последнего входа
| created_at | datetime | да | Дата создания
Связи
Один User.id ко многим UserRole.userId
Один User.id ко многим SecurityAudit.userId
Один User.id ко многим ActionAudit.userId
Логические ссылки на другие БД
Поле team_id ссылается на Team.id (в этой же БД, так как Team здесь).
User.id используются как disabled_by, created_by, exported_by в сущностях центра управления (логические ссылки, без FK).

ActionAudit (Журнал действий над объектами)
Назначение – аудит изменений объектов (CRUD, смена статуса) во всей системе. Может ссылаться на объекты центра управления по их ID.
| Поле | Тип | Обязательность | Описание
| id | string | да | Уникальный идентификатор
| user_id | string | да | Внешний ключ к User
| action | string | да | Текстовое описание действия
| object_type | string | да | Тип объекта: skill, surface, module, domain, dialog, report, export
| object_id | string | нет | Идентификатор объекта (логическая ссылка на объект в любой системе)
| details | object | нет | JSON с деталями изменений
| created_at | datetime | да | Время действия
Связи
Один ActionAudit.userId к одному User.id
Логические ссылки на другие БД
Поле object_id может ссылаться на объекты центра управления (Skill, Surface, Dialog, Report, Export и др.) – связь реализуется на уровне приложения.
