Название задачи
Обеспечить среду для тестирования навыков и конфигураций поверхностей в условиях, максимально приближенных к продакшену, с возможностью просмотра трассировки запроса.
Контекст
Песочница - это стенд, синхронизированный с продом (состав навыков, состояние модулей). Она позволяет командам проверять свои навыки и конфигурации поверхностей до публикации, не влияя на реальных пользователей. Песочница даёт полную трассировку запроса: интент, домен, навык, уверенность, тайминг, результат проверки этики.

| Нет возможности симулировать сбои | Нельзя проверить поведение при ошибках. | Инциденты не тестируются. | Симуляция сбоев (по кнопке).
User Story
Как владелец навыка
Я хочу тестировать свой навык в среде, похожей на прод, видеть полную трассировку запроса и симулировать сбои, чтобы убедиться, что навык работает корректно, прежде чем выкатывать его пользователям.

Функциональные требования
MUST
Чат со стендом: поле ввода, отправка сообщений, отображение ответов ассистента с трассировкой.
Выбор навыка: выпадающий список навыков, доступных для тестирования.
Трассировка запроса: отображение интента, домена, навыка, уверенности (%), тайминга по этапам (пре-роутер, классификатор, навык, итого), статуса проверки этики (пройден/отключён/заблокирован).
Симуляция сбоя: кнопка «Смоделировать сбой» для проверки поведения при ошибках.
Синхронизация с продом: кнопка для обновления состава навыков и состояния модулей.
Управление токенами: отображение и перевыпуск токена песочницы.
SHOULD
Отображение состояния модулей (включены/отключены) с предупреждением, если часть модулей не работает.
История проверок: список предыдущих запросов в песочнице.
COULD
Возможность тестирования с разными ролями (авторизованный/неавторизованный).
Интеграция с автотестами для автоматической проверки.
WON'T
Полноценная среда разработки (только тестирование).
Редактирование навыка в песочнице.
Нефункциональные требования
Ответ ассистента в песочнице - не более 3 секунд.
Трассировка отображается мгновенно после ответа.
Стенд синхронизируется с продом не реже раза в день (или по кнопке).
Ограничения
Технические: песочница использует те же контракты, что и прод; доступна только авторизованным сотрудникам.
ИБ: токен песочницы имеет ограниченный срок действия и доступ только в тестовой среде.
Этапы реализации
MVP (ноябрь 2026): чат с выбранным навыком, базовая трассировка (интент, домен, навык, уверенность), симуляция сбоя.
Этап 2 (декабрь 2026): полная трассировка (тайминг, этика, зависимости), история проверок.
Этап 3 (2027): тестирование с разными ролями, интеграция с автотестами.
Пользовательский путь (владелец навыка)
Переходит в «Песочницу» → выбирает навык из списка.
Вводит вопрос → ассистент отвечает.
Кликает по ответу → видит трассировку: интент, домен, навык, уверенность, тайминг, статус этики.
Нажимает «Смоделировать сбой» → проверяет поведение при ошибке.
Убеждается, что навык работает корректно → возвращается в карточку навыка для отправки на ревью или выката.
