Описание:
Есть Пользователь, ему присваиваются:
Роли (множество ролей)
Области видимости (Множество областей)
Каждая роль содержит в себе список строк - пермиссий. Пермиссия роли отвечает за определенное действие пользователя в ЦАМ панели.
Пермисии хранятся в виде справочника в коде, определяются Бизнесом. Например: Создание Навыка, Просмотр Списка Навыков, Удаление Навыка, Редактирование Навыка, Управление Статусом Навыка...
Каждая область видимости содержит в себе список строк - пермиссий. Пермиссия области видимости отвечает за логирческое разграничения доступа к данным по атрибутивной зависимости.
То есть можно заложить сравнение атрибутов ID создателя навыка == ID пользователя, но нельзя заложить логику на значения атрибутов: Показывать навыки с ID = [1, 2, 3, 5, 9]/
Пример пермиссий области видимости: Смотреть Мои Навыки, Смотреть Навыки Моей Команды, Смотреть Все навыки.
Область видимости отвечает только за доступ к просмотру данных, не регулирует функциональные действия. Не может быть пермиссии области: Редактировать Навыки Моей команды. Для такого нужно в роли иметь пермиссию "Редактирование навыка" и в области видимости иметь перммиссию "Смотреть навыки моей команды".
