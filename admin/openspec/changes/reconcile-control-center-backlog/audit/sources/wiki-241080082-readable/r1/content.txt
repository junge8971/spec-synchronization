Название задачи
Обеспечить формирование и выгрузку структурированных отчётов по диалогам с возможностью выбора полей, периода и фильтров для последующего анализа и презентаций.
Контекст
Отчёты - это инструмент для сбора данных по диалогам в структурированном виде (CSV/XLSX). Они используются аналитиками качества, владельцами навыков и руководством для анализа трендов, подготовки презентаций и внешних отчётов. Админка предоставляет готовые шаблоны и конструктор для создания произвольных отчётов.
Проблематика
| Проблема | Описание | Влияние на команды | Решение
| Отчёты собираются вручную | Данные выгружаются из разных систем и сводятся в Excel. | Трата времени, ошибки, устаревшие данные. | Автоматизированная выгрузка.
| Нет шаблонов | Каждый раз нужно заново определять набор полей. | Неэффективно, нет стандартизации. | Готовые шаблоны для частых сценариев.
| Нет фильтрации | Нельзя выбрать период или канал. | Отчёты содержат лишние данные или неполные. | Фильтры по периоду, каналу.
| Ограниченный экспорт | Только CSV, нет других форматов. | Сложно интегрировать с внешними системами. | CSV + XLSX (в перспективе).

User Story
Как аналитик качества
Я хочу быстро собирать отчёты по диалогам с нужными полями, фильтрами и периодами, чтобы не тратить время на ручную сборку данных и иметь актуальную информацию для анализа.
Как руководитель
Я хочу получать структурированные отчёты по ключевым показателям, чтобы принимать управленческие решения на основе данных.

Функциональные требования
MUST
Готовые шаблоны: Качество за период (еженедельный), Отчёт по навыку, Отчёт по поверхности, Проблемные зоны, Работа операторов.
Конструктор отчётов: выбор периода (произвольные даты), канала (все/конкретный), полей для выгрузки (из списка: Chat Id, Session Id, SSO ID, канал, дата, текст диалога, текст пользователя, текст оператора, время завершения, длительность, причина завершения, кто завершил, оценка, комментарий, тема и категории и др.).
Выгрузка в CSV: скачивание файла с выбранными полями и данными.
Предпросмотр: таблица с первыми строками отчёта (до выгрузки).
Количество строк в отчёте: отображается в предпросмотре и при выгрузке.
SHOULD
Выгрузка в XLSX.
Сохранение шаблонов отчётов для повторного использования.
Планирование периодических отчётов (ежедневно/еженедельно).
COULD
Отправка отчётов на e-mail по расписанию.
Интеграция с BI-инструментами.
WON'T
Редактирование данных в отчётах (только выгрузка).
Визуализация данных внутри отчётов (только таблицы).
Нефункциональные требования
Формирование отчёта для 1000 диалогов - не более 5 секунд.
Предпросмотр обновляется при изменении фильтров - до 2 секунд.
Поддержка выгрузки до 10 000 строк.
Ограничения
Технические: данные для отчётов берутся из ядра ЕСК.
ИБ: доступ к данным ограничен ролями.
Этапы реализации
MVP (ноябрь 2026): готовые шаблоны (Качество за период, Отчёт по навыку), конструктор (период, канал, поля), выгрузка в CSV, предпросмотр.
Этап 2 (декабрь 2026): дополнительные шаблоны (Проблемные зоны, Работа операторов), выгрузка в XLSX.
Этап 3 (2027): планирование отчётов, отправка по e-mail, сохранение пользовательских шаблонов.
Пользовательский путь (аналитик качества)
Переходит в «Отчёты» → видит вкладки «Шаблоны» и «Конструктор».
В «Шаблонах» выбирает готовый шаблон (например, «Качество за период»).
Нажимает «Запустить» → отчёт формируется и скачивается.
Или переходит в «Конструктор» → выбирает период, канал, отмечает нужные поля.
Видит предпросмотр → корректирует фильтры.
Нажимает «Сформировать выгрузку» → скачивает CSV-файл.
Таблицы
Таблица: report_templates
Таблица хранит правила формирования отчётов. Пользователь может открыть шаблон в конструкторе, посмотреть результат и выгрузить CSV.
| Поле | Тип | Назначение
| id | UUID | Идентификатор шаблона отчёта
| created_at | datetime UTC | Дата создания записи
| updated_at | datetime UTC | Дата последнего изменения записи
| deleted_at | datetime UTC, nullable | Дата мягкого удаления записи
| name | string | Название шаблона
| description | text, nullable | Описание назначения и содержимого отчёта
| schedule_type_id | UUID | Способ запуска формирования отчёта
| schedule_config | JSONB, nullable | Параметры расписания; обязательны для cron, null для manual
| period_preset | enum | Правило определения периода отчёта
| period_from | date, nullable | Начало периода; заполняется только для custom
| period_to | date, nullable | Окончание периода; заполняется только для custom
| channel_id | string, nullable | Канал; null означает все доступные каналы
| field_codes | string[] | Упорядоченный список полей; порядок определяет порядок колонок в предпросмотре и CSV
| filters | JSONB, nullable | Дополнительные фильтры формирования отчёта
| created_by_id | UUID | Идентификатор пользователя, создавшего шаблон
Справочник: Поле schedule_type использует ReportScheduleType:
manual: отчёт формируется только по запросу пользователя;
cron: отчёт формируется автоматически по cron-расписанию.
Поле period_preset использует ReportPeriodPreset:
today: текущий день;
last_7_days: последние семь дней;
last_30_days: последние тридцать дней;
previous_month: предыдущий календарный месяц;
custom: фиксированный период из period_from и period_to.
JSONB: Структура schedule_config:
| Поле | Тип | Назначение
| cron | string | Расписание в формате cron: минута, час, день месяца, месяц, день недели
| timezone | string | Часовой пояс расписания, например Europe/Moscow

Таблица: reports
Таблица хранит результаты запусков шаблонов отчётов.
| Поле | Тип | Назначение
| id | UUID | Идентификатор сформированного отчёта
| template_id | UUID, FK | Шаблон, по которому сформирован отчёт
| status_id | UUID | Статус формирования отчёта
| requested_by_id | UUID, nullable | Пользователь, запустивший отчёт; null для автоматического запуска
| requested_at | datetime UTC | Дата и время запроса на формирование
| started_at | datetime UTC, nullable | Дата и время начала формирования
| completed_at | datetime UTC, nullable | Дата и время завершения формирования
| period_from | date | Фактическое начало периода отчёта
| period_to | date | Фактическое окончание периода отчёта
| parameters_snapshot | JSONB | Снимок канала, полей и фильтров шаблона на момент запуска
| file_key | string, nullable | Ключ сформированного файла в объектном хранилище
| file_size_bytes | bigint, nullable | Размер сформированного файла в байтах
| rows_count | integer, nullable | Количество строк в сформированном отчёте
| error_message | text, nullable | Описание ошибки формирования
Справочник: Поле status использует ReportStatus:
pending: отчёт ожидает начала формирования;
running: отчёт формируется;
ready: отчёт успешно сформирован и доступен для скачивания;
failed: при формировании отчёта произошла ошибка.
JSONB: Структура parameters_snapshot:
| Поле | Тип | Назначение
| channel_id | string, nullable | Канал, использованный при формировании; null означает все доступные каналы
| field_codes | string[] | Упорядоченный список полей, использованный при формировании
| filters | object, nullable | Дополнительные фильтры, использованные при формировании
Сервис формирует URL для скачивания по file_key.
