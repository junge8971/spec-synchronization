СТАТУС
1. Инициировать проект на Vite
Нужно поднять новый проект через yarn create vite на React и TypeScript.
vite =>  8.0.0
Минимальная версия Node >= 24, TypeScript включаем в строгом режиме.
В `package.json` сразу заводим базовые команды: `dev`, `build`, `preview`, `typecheck`.
В Vite сразу закладываем multi-entry конфигурацию т.к. виджет будет собираться в несколько точек входа.
2. Настроить пакетный менеджер yarn
Пакетным менеджером делаем Yarn Berry 4 версии
В корне проекта настраиваем `.yarnrc.yml` где указываем внутренний regestry как npmRegistryServer, прописываем scope для @mos-pg-front-tools и @mos-cat, добавляем токен авторизации через REGISTRY_TOKEN. Папку .yarn/releases/ коммитим в репозиторий. Проверка, что всё работает: yarn add -D @mos-pg-front-tools/prettier-config должен пройти без ошибок.
За образец можно взять https://gitlab.mos-team.ru/mosru/front/pg-front-tools/-/blob/dev/.yarnrc.yml
3. Добавить Prettier
Установить и подключить конфиг и зависимости
В prettier.config.mjs просто реэкспортируем готовую конфигурацию из пакета. В .prettierignore исключаем dist, .yarn, coverage. В scripts добавляем format и format:check.
Документация по настройкам - в https://gitlab.mos-team.ru/mosru/front/pg-front-tools/-/tree/dev/packages/configs/prettier-config?ref_type=heads
4. Добавить ESLint
Установить и подключить конфиг и зависимости
Используем Flat Config (ESLint 9 и выше) в файле eslint.config.mjs, не забываем peer-зависимости - prettier и typescript-eslint. Команды lint и lint:fix добавляем в package.json.
Документация по настройкам - в https://gitlab.mos-team.ru/mosru/front/pg-front-tools/-/blob/dev/packages/configs/eslint-config/README.md?ref_type=heads
5. Создать файловую структуру
Код раскладываем по Feature-Sliced Design.
В src/app - живут точки входа .
В pages - экраны чата, приветствия и оболочка webview.
widgets - крупные блоки вроде окна чата, ленты сообщений и поля ввода.
features - отправка сообщений, голос, карточки,
entities  - доменные сущности
shared  - обёртки над UI-kit, API-клиент, конфиги, утилиты и типы.
6. Настройка роутинга в проете
Нужно поставить react-router-dom@8.1 и настроить роутинг в Data Mode через createBrowserRouter и RouterProvider, без legacy <BrowserRouter>.
Конфигурацию маршрутов выносисти в src/app/routesи  там описать route objects с path, Component, loader, action и errorElement.
Страницы из слоя pages подключить как компоненты маршрутов
Также настроить errorBoundary
Документация -  https://reactrouter.com/start/data/routing
7. Настройка стейтменеджера запросов
Подключить @tanstack/react-query для работы состояния запросов.
В src/app/providers создать QueryClient с дефолтными настройками и обернуть приложение в QueryClientProvider.
Ключи запросов и фабрики вынести в shared/api или соответствующие entities.

Виджет встраивается на чужие страницы, поэтому всё React-приложение надо монтировать внутрь Shadow DOM.
Внутрь shadow должны быть проброшены все стили приложения и mos-cat

11. Настроить моки
Необходимо поднять отдельный mock-сервер на Express. Код сервера живёт в mock-server/. Express отдаёт HTTP API и при необходимости поднимает WebSocket-заглушку.
В dev-режиме mock включается по флагу, например `VITE_USE_MOCKS=true`.
Команда `yarn dev:mock` параллельно стартует Express mock-сервер и Vite; в `vite.config` для этого режима прописываем proxy на локальный порт mock-сервера.
Обычный `yarn dev` без флага ходит на реальный backend.
