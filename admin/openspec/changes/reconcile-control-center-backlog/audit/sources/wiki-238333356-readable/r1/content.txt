Название задач
Модуль: Роли и права
Задачи:
Создание функции хранения данных ролей пользователей.
Создание функции хранения данных матрицы прав.
Создание функции хранения данных областей видимости.
Создание функции отображения пользователю реестра ролей.
Создание функции отображения пользователю данных роли.
Создание функции отображения пользователю матрицы прав.

Проблематика
Разработка данного модуля решает проблему разграничения доступа пользователей к Административному интерфейсу и Центру управления.
Определяет ролевую модель, перечень прав и областей видимости для пользователей систем.
