## Context

См. proposal.md. PDF исключает экспорт; HTML формирует CSV из локальных массивов и не является API-образцом. `docs/api/contracts/reports.md` и MOS-919 также не предоставляют готового сервера выгрузки диалогов. Поэтому design разделяет подтверждённую потребность и заблокированную интеграцию.

## Goals / Non-Goals

**Goals:** сохранить три режима выборки и два формата строк, не выдавая частичный CSV за полный; сформулировать проверяемый контрактный gate.

**Non-Goals до gate:** новый endpoint, фоновая очередь, polling, CSV encoder, расширение общего transport ради неизвестного протокола, массовый обход detail/search в браузере.

## Decisions

1. **BLOCKED API:** неизвестные ниже материально влияют на реализацию. До их принятия не выполнять post-gate задачи и не считать полный change готовым к реализации только по наличию tasks.md. После решения обновить design/spec/tasks конкретным wire-контрактом до кодирования.
2. **Матрица согласования с backend/продуктом:**

| Область   | Требуемое решение                                                                                          |
| --------- | ---------------------------------------------------------------------------------------------------------- |
| API       | URL, метод, тело, ответ, коды ошибок; файл либо задание и его жизненный цикл                               |
| Выборка   | весь selection, отмеченные chat_id, один chat_id; сочетание IDs и selection; отсутствующие/недоступные IDs |
| Период    | заменяет период selection или пересекается с ним; действует ли на явно выбранные IDs                       |
| Колонки   | коды, порядок, обязательные поля и допустимые варианты для каждого формата                                 |
| Сообщения | представление автора, времени, текста, вложений и оснований; порядок диалогов/сообщений                    |
| CSV       | кодировка, BOM, разделитель, quoting, переносы строк, защита от spreadsheet formulas                       |
| Параметры | схема строк в конце CSV, их отделение от данных, какие чувствительные критерии включаются                  |
| Объём     | лимит записей/размера/IDs, большой экспорт, timeout, отмена и повтор, атомарность файла                    |
| Доставка  | MIME, Content-Disposition/имя файла, срок готовности/хранения, ошибки и безопасное скачивание              |

3. **Единый selection:** экспорт всего отбора использует применённый объект MOS-1037 со сложными условиями MOS-1038, не draft и не только загруженные items. Backend отвечает за полноту, frontend не восполняет отсутствующий export endpoint циклом поиска.
4. **Отметки — отдельное состояние:** после gate хранить chat_id в рамках применённого отбора. Предлагаемое правило для подтверждения в gate: добавление страницы и смена сортировки сохраняют отметки, смена отбора очищает их; «Отметить показанные» касается лишь загруженных строк, снятие не удаляет скрытые отметки. Не вводить «выбрать всё найденное» через checkbox: для этого есть режим всего отбора.
5. **UI после gate:** одна feature с точками входа реестра/карточки, без импорта одной page из другой. Форма периода, формата строк, колонок и флага параметров строится по принятому контракту; неподдерживаемые комбинации не отправляются. Не считать disabled-колонки HTML окончательной схемой формата по сообщениям.
6. **Правдивые состояния:** до gate сохранять отсутствие работающего экспорта; если кнопка присутствует, рядом понятное объяснение недоступности. После gate различать создание задания (если принято), готовность файла и скачивание; не сообщать «скачано» по одному успешному POST. Ошибку JSON не сохранять как CSV, частичный файл не объявлять полной выгрузкой.

## Risks / Trade-offs

- Новый контракт может потребовать async job → не строить заранее ни polling, ни синхронный Blob transport; решение обновляет план.
- Утечка критериев/формулы из текста → определить серверную CSV-политику и проверить её fixtures; HTML-escaping CSV не защищает.
- Большая выдача → требуется серверный лимит/способ доставки, не memory buffer всех диалогов браузера.
- Неопределённый период + IDs → gate запрещает молчаливое отбрасывание отмеченных строк.

## Migration Plan

Сейчас только planning и при необходимости честное unavailable-состояние. После отдельного контракта пересмотреть этот change, опубликовать DTO, реализовать выбранный способ выгрузки и проверить полный результат на нескольких страницах. Disabled-состояние не закрывает оставшиеся задачи. Откат возвращает недоступность без генерации урезанного CSV.
