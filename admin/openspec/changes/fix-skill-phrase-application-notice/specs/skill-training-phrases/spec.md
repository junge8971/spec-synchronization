## MODIFIED Requirements

### Requirement: Saved version without invented application status

UI SHALL показывать сохранённую версию навыка из ответа API и сообщать, что применённая версия и состояние дообучения не предоставляются текущим API. Сохранение MUST NOT объявлять новую версию активной или обещать вымышленный срок. Полный индикатор применения отложен по решению пользователя. Сообщение об отсутствии данных SHALL быть доступно непосредственно на вкладке «Обучающие фразы» в режимах просмотра и редактирования, в том числе после подтверждённого сохранения опубликованного навыка. Ошибка последующего GET карточки MUST NOT отменять подтверждённое сохранение или скрывать это сообщение; UI SHALL сохранять подтверждённые группы и сохранённую версию, отдельно сообщая об ошибке обновления карточки.

#### Scenario: Saved version only

- **WHEN** сервер подтвердил сохранение новой версии
- **THEN** интерфейс показывает эту сохранённую версию и отсутствие данных о применении, не объявляя дообучение начавшимся или завершённым

#### Scenario: Notice in phrase viewing and editing

- **WHEN** пользователь открывает вкладку «Обучающие фразы» и переходит между просмотром и редактированием
- **THEN** на этой вкладке доступно сообщение, что применённая версия и состояние дообучения не предоставляются текущим API, без необходимости перехода на вкладку проверок

#### Scenario: Published skill confirmed save

- **WHEN** API подтверждает сохранение фраз опубликованного навыка
- **THEN** UI показывает подтверждённую сохранённую версию и сообщение об отсутствии данных о применённой версии и дообучении, не утверждая, что фразы уже применены или обучение началось

#### Scenario: Confirmed save followed by read failure

- **WHEN** API подтвердил сохранение фраз и последующий GET карточки завершился ошибкой
- **THEN** подтверждённые группы и сохранённая версия остаются доступными вместе с сообщением об отсутствии данных о применении и дообучении; ошибка обновления карточки показана отдельно и не выдаётся за ошибку сохранения или состояние обучения
