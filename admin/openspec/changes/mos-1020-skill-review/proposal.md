## Why

MOS-1020: существующая вкладка «Ревью» пока заглушка. Нужна очередь с материалами навыка и серверным решением по конкретной версии; два присланных скриншота относятся к одной Jira-задаче.

## What Changes

- Очередь, выбор навыка, просмотр анкеты, обучающих фраз и результатов проверок.
- Пять критериев: завершимость сценария, вариативность формулировок, редакционная политика, достаточность фраз, понятное поведение при ошибке.
- Согласование и возврат; для возврата обязательны причина и текст.
- Обновление очереди/карточки только после серверного решения, защита от решения по устаревшей версии.
- Не включать выкат, клиентские роли и permissions.

## Capabilities

### New Capabilities

- `skill-review`: очередь и решения по навыкам.

### Modified Capabilities

- `control-center-shell`: заменить обязательную заглушку ревью рабочим содержимым при наличии согласованного review API, сохранив остальные незавершённые точки входа.

## Impact

- `app/pages/skills/ui/skills-page.tsx`, новый widget очереди, features решения, `app/entities/skill/`.
- **BLOCKED API:** `docs/api/contracts/openapi.json` не содержит review queue, решения, критериев, причин возврата и version guard.
- MOS-945/MOS-1019 определяют данные фраз и проверок; их версии должны совпадать с предметом ревью. Отдельная приёмка без ожидания MOS-1021.
