## Why

[Jira MOS-1256](https://task.mos-team.ru/browse/MOS-1256): [FE][Обратная связь] Реализовать смену статуса и удаление опросника.

Нужна отдельная реализуемая поставка этой FE-подзадачи по обновлённому API и принятой границе прототипа. План, приёмка и выполнение учитываются отдельно от остальных задач MOS-1246.

## What Changes

- Действия «Приостановить», «Возобновить», «Выключить» и «Удалить» в сохранённой карточке. Смена статуса использует PUT, удаление — подтверждённый soft-delete.
- Сохранить ограничения API, ввод при ошибках, доступность и действующую безопасность.
- Реализовать область задачи внутри `app/optional/feedback` по границе MOS-1249 и примеру базы знаний; новая UI-policy, mappings permissions и новые ограничения интерфейса по пользователю не входят.

- Использовать общее подтверждение выключения в действиях карточки и при сохранении формы. Предлагать явно сохранить изменения перед отдельным действием.

### Deferred scope

Статус archived не используется: контрактный код — disabled. Восстановления удалённого опросника в API нет.

## Capabilities

### New Capabilities

- `feedback-lifecycle`: PUT draft/active/paused/disabled, подтверждение выключения и soft-delete, dirty-защита и обновление server state.

### Modified Capabilities

Нет. Общие capabilities HTTP, действующих защитных механизмов и MPMM сохраняются; scope соседних FE-подзадач сюда не переносится.

## Impact

Владелец реализации и тестов — `app/optional/feedback`. Внешние подключения идут через публичный `index.ts` и отдельные framework route entrypoints; composition находится в application, нижние FSD-слои не зависят от optional.

Действия карточки/реестра и инвалидирование запросов через внутреннюю модель feedback.

Зависимости: [MOS-1250](../archive/2026-10-20-mos-1250-feedback-registry/proposal.md); [MOS-1251](../archive/2026-10-23-mos-1251-feedback-editor/proposal.md)

Граница поставки — редактор карточки и синхронизация его операций с реестром. Исполнение правил и сбор реальных ответов пользователей относятся к отдельным задачам.
