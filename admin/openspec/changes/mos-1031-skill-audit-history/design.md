## Context

См. proposal.md. `history-tab.tsx` — unavailable; подключённого frontend-reader нет. Отдельный документальный контракт сервиса аудита принят как evidence в D-050 (`../reconcile-control-center-backlog/audit/reports/DELTA-AUDIT-SERVICE-CONTRACT.md`), но не как согласованная браузерная интеграция. Локальный `docs/api/contracts/audit.md` отсутствует; его отсутствие не доказывает отсутствие методов сервиса. В прототипе сопоставление по названию непригодно для реальной истории.

## Goals / Non-Goals

**Goals:** история одной устойчиво идентифицированной сущности и серверная пагинация.

**Non-Goals:** полный экран аудита, генерация локальных audit events, отображение секретов в подробностях.

## Decisions

- **BLOCKED API/integration:** подтвердить принятие документального Query API для frontend-reader: маршрутизацию и разрешённый адрес credentials, авторизацию чтения, wire-тип сущности навыка и ID-фильтр, отображение событий, время/автора/действие/details, сортировку, период/retention, pagination, redaction и eventual consistency. Публикация отдельного сервиса не снимает этот gate и не меняет штатную модель сессии. Не придумывать URL `/audit` как backend endpoint.
- Предметный клиент чтения аудита разместить в entities с публичным API; history-tab использует его без импорта другого widget журнала. Точное выделение entity определяется принятым контрактом, не абстракцией «универсальные события» заранее.
- Каждый запрос содержит тип и ID, ключ кеша — те же идентификаторы плюс параметры страницы. Название используется только для представления.
- Мутации навыка при наличии аудита инициируют refetch соответствующей истории; не добавлять фальшивую строку «успех» до её появления в Query API. Учитывать согласованную задержку появления события.
- Empty означает успешный пустой ответ; ошибка имеет retry. Автора показывать из записи, не из вымышленного текущего пользователя. Details рендерить безопасно, без raw HTML и раскрытия секретов.

## Risks / Trade-offs

- Навык переименован/есть тёзка → фильтры по type+ID сохраняют историю без смешения.
- Поздний ответ предыдущего навыка → изоляция query key/AbortSignal.

## Migration Plan

После gate заменить только вкладку истории; общий `/teams?tab=audit` остаётся вне scope. Откат возвращает unavailable, серверный аудит не изменяется. Принимать отдельно от всех остальных mutations.
