## Purpose

Предоставить серверную историю изменений конкретного навыка без смешения одноимённых сущностей и потери записей при переименовании.

## ADDED Requirements

### Requirement: Audit entity identity

При наличии согласованного Query API каждый запрос истории SHALL фильтроваться по типу сущности и skill ID. Название MUST NOT использоваться как идентификатор или замена серверного фильтра. Без API SHALL сохраняться unavailable вместо локального аудита.

#### Scenario: Renamed skill

- **WHEN** навык переименован и пользователь открывает его историю
- **THEN** запрос использует прежний устойчивый ID и возвращает также записи до переименования

#### Scenario: Same names

- **WHEN** два навыка имеют одинаковое название
- **THEN** история каждого содержит только записи его типа и ID

### Requirement: Server audit presentation

UI SHALL показывать время, автора, действие и доступные подробности серверных записей, соблюдая согласованные порядок и пагинацию. Автор MUST NOT подменяться вымышленным текущим пользователем. Подробности MUST NOT исполнять HTML/скрипты или раскрывать секреты.

#### Scenario: Next page

- **WHEN** пользователь запрашивает следующую страницу истории
- **THEN** сохраняются фильтры типа и skill ID и используется контрактная пагинация

### Requirement: Honest history refresh and states

UI SHALL различать loading, успешный empty и error/retry. Обновление после мутации SHALL читать аудит, а не добавлять локальную запись об успехе. Поздний ответ другого навыка MUST NOT заменять текущую историю.

#### Scenario: Audit event not yet visible

- **WHEN** мутация навыка успешна, но Query API ещё не возвращает событие
- **THEN** UI не создаёт вымышленную запись и следует согласованным правилам обновления

#### Scenario: Failed history request

- **WHEN** запрос завершился ошибкой
- **THEN** показаны ошибка и повтор, не пустая история

#### Scenario: Skill changed during request

- **WHEN** после выбора другого навыка приходит ответ истории предыдущего
- **THEN** записи предыдущего навыка не отображаются как история текущего
