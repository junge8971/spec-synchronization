## Purpose

Показывать в обзоре навыка измеримые результаты за 30 дней с достоверными определениями показателей и достаточности выборки.

## ADDED Requirements

### Requirement: Thirty-day skill outcome

При наличии согласованного API обзор SHALL показывать за 30 дней диалоги с участием навыка, успешность сценариев и полученные вложения. UI SHALL обозначать согласованный период и единицы и MUST NOT заменять данные навыка общим дашбордом или локальной выборкой диалогов.

#### Scenario: Outcome overview

- **WHEN** сервер возвращает показатели выбранного навыка за согласованный период
- **THEN** показаны диалоги, успешность и вложения именно этого навыка с подписью периода

### Requirement: Answer ratings and coverage

UI SHALL показывать долю хороших ответов, общее число и число плохих оценок, охват и порог. Оценки оператора MUST NOT включаться в оценки ответов ассистента. При недостаточной выборке SHALL показываться объяснение минимальной выборки вместо необоснованной оценки качества.

#### Scenario: Mixed rating targets

- **WHEN** данные содержат отдельные оценки ответов ассистента и работы оператора
- **THEN** блок навыка использует только согласованную область оценок ответов, без суммирования с операторскими

#### Scenario: Insufficient ratings

- **WHEN** число оценок ниже согласованного минимума
- **THEN** UI объясняет недостаточную выборку и не показывает её как подтверждённую норму или нарушение

### Requirement: Scenario step metrics

UI SHALL показывать целевые шаги, фактическое среднее, медиану, долю длинных и незавершённых сценариев по серверным определениям. Отсутствующие значения MUST NOT заменяться нулями или вычисляться по неполному списку.

#### Scenario: Step distribution

- **WHEN** API возвращает полный набор метрик шагов
- **THEN** видны целевое значение, среднее, медиана и обе доли с согласованными единицами

### Requirement: Independent analytics availability

Ошибка аналитики MUST NOT скрывать анкету. UI SHALL различать отсутствие API, ошибку с повтором, отсутствие данных и измеренный ноль.

#### Scenario: Zero versus missing

- **WHEN** число вложений равно 0, а медиана отсутствует
- **THEN** вложения показаны как 0, медиана — как отсутствие данных

#### Scenario: Analytics request fails

- **WHEN** API аналитики не отвечает
- **THEN** анкета остаётся доступна, блок аналитики показывает ошибку и повтор без фиктивных значений
