## Why

MOS-1023: сведения о транспортных токенах навыка должны приходить с сервера, а не генерироваться интерфейсом. В текущей карточке фиктивных токенов уже нет, но отсутствует поддержанный сценарий по контурам.

## What Changes

- Серверные состояния токенов, контур, область действия, сроки и согласованные действия раскрытия/перевыпуска.
- «Не выдан» показывать только при соответствующем серверном состоянии, не при ошибке загрузки.
- Передавать в песочницу skill ID без секрета в URL; использовать общую предметную модель токена в карточке и песочнице.
- Не включать вход пользователя, сессию, RBAC и произвольное хранение секретов.

## Capabilities

### New Capabilities

- `skill-environment-tokens`: безопасное представление и операции с токенами навыка по контурам.

### Modified Capabilities

Нет. До появления API сохраняется unavailable, а не фиктивные значения.

## Impact

- `app/entities/skill/`, подключение карточки и существующая точка входа песочницы.
- **BLOCKED API:** `docs/api/contracts/openapi.json` содержит auth_type=transport_token, но не токены, контуры, раскрытие, сроки и перевыпуск. Surface sandbox не покрывает модель токена навыка.
- MOS-1019 задаёт доступность песочницы; реализация диалога песочницы вне задачи, интеграция общего token API — в задаче.
- Самостоятельная приёмка MOS-1023, включая отсутствие секретов в URL/логах/постоянном хранилище.
